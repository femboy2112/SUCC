# Lonely Runner campaign: research-local claim supplement

These identifiers are deliberately unregistered research-local labels. This
supplement changes no historical theorem ID or archived source. Mathematical
correctness, exact execution, Lean exports, literature priority, and external
peer acceptance are separate statuses. No general Lonely Runner conjecture is
claimed. The original BBP, RH, and Collatz programs are unchanged.
