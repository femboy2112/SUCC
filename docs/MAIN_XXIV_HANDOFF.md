## 3. The exact theorem to prove next

Let $`e(t)=\exp(2\pi i t)`$ and $`Y_n=16^nx=U_n(0)+T_n`$. The canonical target is

```math
\forall h\in\mathbb Z\setminus\{0\}:\qquad
W_{N,h}:=\frac1N\sum_{n=0}^{N-1}e(hY_n)\longrightarrow0.
```

Choose the equivalent [signed Basel interface](../research/2026-11-10/basel_crt_omega_phasebridge/SIGNED_BASEL_TAUBERIAN.md):

```math

```

**Missing theorem, with all quantifiers:**

```math
\forall h\in\mathbb Z\setminus\{0\},\ \forall\epsilon>0,
\exists A_0(h,\epsilon),\ \forall A\in\mathbb N,\ A\ge A_0:
\qquad A|F_h(A;0)|\le\epsilon.
```

The estimate must be derived from the **actual four-pole source and original zero
seed**. It is equivalent to π's base-16 normality by the existing bounded-sequence
Basel–Tauberian theorem and classical Weyl criterion. Its elementary positive bound
is only $`|F_h(A;0)|\le A^{-1}+O(A^{-2})`$; replacing it by another fixed multiple
of $`1/A`$ does not establish the missing little-o saving.

For $`\omega_A=\sum_{n=A}^{2A-1}n^{-2}`$, define
$`B_A(h)=[F_h(A;0)-F_h(2A;0)]/\omega_A`$.
The proved inverse-Abel bounds include

```math

\le5\sup_{n\ge A}n|F_h(n;0)|
\le10\sup_{B\ge A}|B_B(h)|.
```

Thus an independently vanishing bound on **all sufficiently late integer shells**
would close the target. A selected sequence of finite epochs, a fixed seed-depth
fingerprint or one mixed 2→3 mode cannot pay this supremum or the all-mode quantifier.

```math

\left(1-\frac\ell L\right)
\mathrm{Re}\!\sum_{n=B}^{2B-1-\ell}

```

