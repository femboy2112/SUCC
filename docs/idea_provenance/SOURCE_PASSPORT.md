## Five different provenance families

| Family | What it actually proves | What it does NOT prove |
|---|---|---|
| USER direct chat utterance | Who asked what, in that local dialogue (if exact text is present) | An externally authenticated mathematical theorem, a stable public permalink, or the user's belief in a mathematical interpretation proposed later |
| USER reconstructed past-chat summary | A recoverable broad theme of prior dialogue | An exact verbatim quotation, exact first priority or fully sourced timestamp unless transcript independently available |
| Assistant steelman | A proposed mathematical interpretation, with new hypotheses/definitions | That the user explicitly asserted it, that it is a known historical meaning, or that its hypotheses hold for the true carrier |
| Repository paper/code/CI | Source-labelled mathematical derivation and/or finite tests, on an exact commit | Scholarly novelty, independent referee, all-index arithmetic asymptotics, physical instantiation |
| External literature/music | Established published precursors and metadata where cited | Proof that source-specific SUCC reuses have paid new global arithmetic hypotheses |

Conversations are not currently archived into this repository as public export with per-message cryptographic hashes. Do **not** pretend an old chat paraphrase is a signed original quote or fabricate its URL. A later exported, user-approved transcript can be added as a separate source with digest and explicit consent.

Does **not** establish its scientific source.
5. **Spectrogram context:** [CMU computer-music notes](https://www.cs.cmu.edu/~15322/book/ch10/09.html), [Mixmag history](https://mixmag.net/feature/spectrogram-art-music-aphex-twin), [MusicBrainz annotation](https://musicbrainz.org/release/0a25ae72-8a79-37f4-a697-591f4364e0ab) — documented spectrogram image as artist-authored encoding.
