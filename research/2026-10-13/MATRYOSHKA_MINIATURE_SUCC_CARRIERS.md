## 1. Define the original parent, not just a guessed simulation

For this finite deterministic laboratory, a parent carrier contract is

\[
E=(C,A,\{T_a:C\rightharpoonup C\}_{a\in A},r:C\to O,\mathcal P,\sigma),
\]

where \(C\) is a finite set of *current whole-system states*; \(A\) is the complete declared finite physical action menu; each \(T_a\) is partial (its undefined domain is a refused unsafe operation); \(r:C\to O\) is an existing publicly available carrier report; \(\mathcal P\subseteq C\) contains the states covered by declared preparation certificates; and \(\sigma\) is the common model/source version. An external source original label, when present, must be preserved separately through all current-state changes. The label \(\sigma\) does **not** authenticate a real laboratory apparatus.

The proposed miniature is a Moore automaton

\[
M=(Q,B,\{\delta_b:Q\to Q\},\lambda:Q\to O',q_0,\sigma).
\]

A *compiled action* is a source-independent finite word \(w_b\in A^*\), with a length/budget contract, whose parent interpretation is \(T_{w_b}\), defined only when every primitive action is safe in the actual intermediate state. Every intermediate receipt remains a causally performed parent event. The miniature's 'one SUCC' is a **macro logical step**, not one performed physical event. Runtime access to private source labels is never provided.

## 2. M01 — sufficient and necessary exact invariant subcarrier conditions (PROVED LOCAL)

Assume a one-to-one encoding \(e:Q\hookrightarrow C\), an initial legitimate preparation of \(e(q_0)\), and a physically executable encoded carrier state for each claimed mini state. Require, **for every** \(q\in Q,b\in B\),

\[
\boxed{\begin{aligned}
r(e(q))&=\lambda(q),\\
T_{w_b}(e(q))&=e(\delta_b(q)),
\end{aligned}}
\tag{M01}
\]

and every intermediate source action of \(w_b\) must be enabled. Then the image \(e(Q)\) is invariant under all compiled macro actions and implements the exact miniature from any encoded mini state.

**Proof:** At the empty word, initial states and reports agree. Suppose the parent reaches \(e(q)\) after some compiled miniature history. Equation M01 executes the next macro lawfully, reaches \(e(\delta_b(q))\), and reports the correct child value. Induct on word length. All raw parent intermediary states, actions and reports are retained by the trace receipt. The converse is immediate if 'implements at each state' *means exactly* that the designated interpreter preserves the state after each primitive macro: testing singleton words recovers M01. The conditions are a definition-relative iff, not a physical ontology theorem.

**Actual witness:** Parent \(\mathbb Z/4\mathbb Z\), primitive \(T(x)=x+1\), parent public report \(r(x)=\lfloor x/2\rfloor\). Encode \(e(0)=0,e(1)=2\); compile mini flip by the physical two-step macro \(T^2\). Then \(T^2e(q)=e(1-q)\), and all reports match. Parent state 0 is explicitly preparable. A one-step macro is rejected. A reported two-step mini SUCC counts **two actual parent SUCCs**.

\[

**Proof:** Apply the parent/intermediate commuting squares successively for each letter in \(v_b\); the composite squares telescope. ## 7. M06 — exact stochastic mini realization requires the JOINT instrument (PROVED LOCAL)

For probabilistic parent \(C\), let \(K_a(c;z,c')\in\mathbb Q_{\ge0}\) be a complete normalized public-report/next-current-state kernel, and for mini \(Q\), let \(L_b(q;z,q')\) be its proposed kernel. A surjective \(\pi:C\to Q\) is source-correct for the selected one-step physical action \(a\) implementing mini action \(b\) **for every original current-state prior** iff

\[
\boxed{\sum_{c':\pi(c')=q'}K_a(c;z,c')
=L_b(\pi(c);z,q')
\quad\forall c,z,q'.}
\tag{M06}
\]

**Necessity:** use an original Dirac prior at each \(c\). **Sufficiency:** linearity sends every current-state prior to the exact same unnormalized public receipt and next mini-state distribution; induct on the public history for all policies whose actions depend only on lawfully retained public receipts. Zero-mass branches do not manufacture posteriors. This is **strong lumpability with source-visible report labels**, already foreshadowed by C17/NO-GHOST; priority is classical.

**Countermodel:** Parent output receipt `H/T` and next decoded state `a/b` each have the correct fair marginals. The genuine row couples `(H,a)` and `(T,b)` with probability 1/2 each. One mutated hidden parent state instead couples `(H,b)` and `(T,a)` with probability 1/2 each. Separate outcome and endpoint marginals agree; the **joint** instrument differs and the exact verifier rejects it. Thus a model cannot silently manufacture a causal probability coupling.

Single-step stochastic instruments are implemented here. Arbitrary stochastic multi-event macros would require all intermediary receipts and source-history conditional kernels, not just an endpoint transition.

## 8. Direct bridge to the zero-centered dual Wold shells

The previous branch constructs the isometry \(U_qf(x)=\sqrt q f(qx)\) on the reciprocal-cell Hilbert carrier and its orthogonal shells \(Q_n=P_n-P_{n+1}\). At every finite N,

\[
f=\sum_{j<N}Q_j f+P_Nf,
\quad \|f\|^2=\sum_{j<N}\|Q_jf\|^2+\|P_Nf\|^2.
\]

For *finite reports* of a source supported on finitely many reciprocal cells and finitely many allowed rational coefficients, a finite miniature automaton can tabulate and verify the finite shell outputs exactly: store an input transcript as a finite Moore/Mealy state, evaluate the rational block averages, retain the input-event provenance, then send it to E for the certified mathematical join. This is a genuine **bounded mathematical instrument** but not an unearned physical measurement: the input coefficient reports require real lawful access to the original source. If a report alphabet has \(d\) symbols and E actually receives \(K\) coefficients, a naive prefix-store mini needs at most \(\sum_{j=0}^K d^j\) transcript states before any minimization; a realized machine must additionally pay the physical memory and causal input costs.

**Exact negative control remains:** for any fixed N, the parent source \(f_N=\mathbf1_{[q^N,2q^N)}\) has first N complementary shells zero, although \(f_N\ne0\). Its remaining energy is \(1/(2q^N)\). Thus no finite collection of shell-miniatures has global uniform operator-norm completeness over the full Hilbert source class. A miniature can be *complete for a declared finite target* without having completed infinite observation.

**M07 — additive obstruction at *every* finite dual-E depth (PROVED LOCAL).** For any integer q>=2 and any n>=1 let m=q^n, f=delta_m, let P_n be the q-dilation range projection, and let T_S f(k)=f(k+1) be the additive successor pullback. At cell k=m-1, the full quotient-block formula gives

\[

\]

But T_S delta_m=delta_(m-1), whose support lies strictly before the first permitted P_n block; hence P_n(T_S delta_m)=0. Therefore

\[
\boxed{\bigl[(T_SP_n-P_nT_S)\delta_{q^n}\bigr](q^n-1)
=\frac{2}{q^n+1}>0}\quad\forall q\ge2,\ n\ge1.
\tag{M07}

This strengthens the old single-depth 2/3 witness into a **uniform-in-depth algebraic counterexample** to naive SUCC-equivariance of the Wold-shell construction. The coefficient tends to zero as n grows, but it never vanishes at a finite positive depth; it does not assert a lower bound uniform in depth, operator norm divergence, or an RH obstruction. The exact new test runs q=2,3,5,6 and depths 1..4. Authentic prime labels are a *separate* source gate: q=6 obeys the same geometric formula.

## 9. What would actually make E more capable?

- A **better implementation within existing closure**: model synthesis finds a composite lawful experiment, simpler quotient, lower cost, or source proof that E had not previously discovered. This changes *practical* capability, not the full mathematical information closure of old physical actions.
- A **new physical/semantic carrier extension**: E builds a sensor or apparatus that adds genuinely different source coupling; its creation is a real source-changing process \(F:C_h\rightsquigarrow C_{h+1}\) with apparatus memory, preparation, cost, reports, version and safe-domain gates. Its new action/reading must be checked against the actual source and cannot be conjured by extending a model grammar.
- A **mathematical theorem extension**: E proves a new law that narrows the admissible original-source class. This can make an existing observation decisive without any new physical measurement, but the theorem's axioms/derivation remain independently proof-bearing.

These are different repairs and must not be collapsed into 'E now has access to all unobservable states'. Only actual admitted instruments or sound new premises alter the source-truth closure.
