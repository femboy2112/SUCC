# SWM-A01 — Source-indexed support and fibred repair

## 1. Original question
Does universal deterministic observational repair commute with a genuine source change, and which support-transport squares are exact?

## 2. Existing mathematical context
The power-set indexed poset has inverse image as reindexing and existential direct image as its left adjoint. The finite-set Beck–Chevalley theorem is already implemented in `covariant_proof_descent.py`; target preservation and observational covariance are separate gates in `field_context_descent.py` and `formal/EODCS_CausalDescent.lean`. This dossier does not claim academic novelty.

## 3. Proposed SUCC objects
A source is a set X with a common action alphabet A, total maps T_a:X→X and report h:X→O. Eq(X) is ordered by relation inclusion. StEq(X) contains the action-stable equivalences. A strict source morphism f:X→Y obeys fT_a=T'_af and h=h'f for every declared action. A belief B⊆X×X stores **original/current** pairs. Reindexing equivalences is f*R={(x,y):f(x) R f(y)}.

## 4. Candidate theorem
For any equivalence R on X define I_X(R)=⋂_{w∈A*}(T_w×T_w)⁻¹R, including the empty word. Then:

1. I_X is the right adjoint to StEq(X)↪Eq(X).
2. For every strict source morphism, **I_X(f*R)=f*(I_YR)**. Surjectivity is unnecessary.
3. For q:X→X/I_X(ker h), Q=q×q and the quotient action, every B, a and o satisfy Q[U^X_{a,o}(B)]=U^Q_{a,o}(Q[B]), where U_{a,o}(B)={(x₀,T_ax):(x₀,x)∈B,h(x)=o}. Original-target homogeneity is also preserved if τ:X→V factors through q on the origin coordinate.

## 5. Proof attempt — complete local derivation
Each pulled-back R is an equivalence, so their intersection is. If x I_X(R) y, then for each a and word w, T_wT_ax R T_wT_ay, because the composite is another allowed word; hence I_X(R) is stable. The empty word makes it contained in R. Any stable E⊆R satisfies T_wx E T_wy for every word by induction, hence E⊆I_X(R). This is precisely E⊆R iff E⊆I_X(R), giving the coreflection.

The source square iterates: fT_w=T'_wf. Therefore x I_X(f*R)y iff fT_wx R fT_wy for every w iff T'_wf(x) R T'_wf(y) for every w iff f(x) I_Y(R)f(y). This proves the base-change equality.

For belief transport, apply Q to the displayed comprehension. The equations qT_a=bar(T)_aq and h=bar(h)q convert it exactly to the quotient comprehension. Every abstract pair used there has a representative in B by definition of direct image. No saturation assumption is needed for this **forward filtered image** identity. If τ=bar(τ)q, the set of target values on original coordinates is unchanged, so all finite adaptive report-tree terminals and common action costs are preserved.

## 6. Crucible
The independent word oracle verifies 1,080 unary three-state/source-partition and 128 two-action two-state/source-partition instances. Strict nonsurjective 2→3-state source maps verify **7,200** partition/base-change instances. All 512 origin/current beliefs for one destructive three-state source, two actions and two outputs verify **2,048** update equalities.

A report-preserving map alone fails: X={0,1}, T_X=id, h_X=(0,0); Y={0,1,2}, T_Y=(0,2,2), h_Y=(0,0,1), f=(0,1). Repair on X is indiscrete; pullback of repaired Y is discrete. The missing equation is fT_X=T_Yf.

An arbitrary inverse-image claim fails even with a lawful quotient: X={0,1}, q constant, T reset to 0 and S={1}. T⁻¹S=∅ whereas q⁻¹(bar(T)⁻¹q[S])=X. Saturated S repairs this equality. Endpoint-only support also loses original truth after reset; immutable original/current pairs avoid that erasure.

## 7. Verdict
**PROVED LOCAL.** A paper proof plus independent exact bounded verification of a reusable fibred coreflection and belief intertwiner. Ingredients are classical; no formal kernel verification or external-world theorem follows.

## 8. Remaining obstruction
For relational/stochastic sources the deterministic preimage intersection need not be the right behavioral relation. The next verdict-changing lemma is a source-typed coupling/bisimulation analogue of the exact belief-image square, with a declared common report law. For arbitrary proof-support categories one must separately provide target/proof transport; Eq(X) alone does not supply it.
