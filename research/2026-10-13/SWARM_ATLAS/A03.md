# SWM-A03 — Compatible shadows can have no global source

## 1. Original question
Does agreement of local observational supports on every overlap imply a lawful global model?

## 2. Existing mathematical context
`constructive_gluing_tower.py` and `local_global_descent.py` require complete source-edge coverage before assembling actual charts. General fibred descent requires cocycle data, [Stacks, tag 02ZC](https://stacks.math.columbia.edu/tag/02ZC). Compatible support families versus global sections are studied in [Abramsky–Brandenburger, 2011](https://arxiv.org/abs/1102.0264). This is a finite constraint example, with no claim of quantum realization.

## 3. Proposed SUCC objects
The global coordinate set V={x,y,z}, alphabet {0,1}, and contexts xy,yz,xz. Each local relation R_C⊆{0,1}^C is a set of possible reports. Restrictions are coordinate projections. The possible global source is G=⋂_C π_C⁻¹R_C. This is a subpresheaf of assignment sets; it is not assumed to be a sheaf.

## 4. Candidate theorem
For any finite coordinates and relations, G is precisely the global assignments satisfying every local report relation. Pairwise equal projected supports do **not** imply G≠∅. If instead actual individual assignments s_C agree on every overlap and the contexts cover V, there is exactly one glued assignment.

## 5. Proof attempt — derivation and decisive counterexample
Set R_xy=R_yz={(0,0),(1,1)} and R_xz={(0,1),(1,0)}. Every overlap is one coordinate and projects to {0,1}; hence every pair is support-compatible. A global assignment would satisfy x=y=z and x≠z, a contradiction. Thus G=∅.

For actual matching assignments, define s(v)=s_C(v) for any context containing v. Agreement makes this independent of C, and coverage makes it total. It restricts to every s_C and uniqueness follows coordinatewise. The failed model uses sets of alternatives, rather than an actual matching section family; there is no contradiction with the ordinary assignment sheaf.

## 6. Crucible
The exact evaluator enumerates all eight global bit assignments, verifies every pairwise projected-support equality, and finds zero global sections. Mutating the third relation to equality yields exactly (0,0,0) and (1,1,1). Removing a constraint admits false completions of the original source contract, so successful partial gluing cannot be promoted to full-source gluing. Malformed coordinate domains are rejected.

## 7. Verdict
**REFUTED** for the proposed general inference “pairwise-consistent support ⇒ global realization.” The repaired matching-section statement is **CLASSICAL** and proved above. No sheafification completion is claimed to manufacture a physically possible source.

## 8. Remaining obstruction
To make source-aware gluing sufficient, specify a cover class and prove effective descent or an acyclicity/extension condition for its relation family. The next lemma should characterize exact join-tree hypotheses under which overlap-compatible finite supports always extend, including provenance coverage.

## 9. Cross-domain connection
A04 encodes the same contradiction as a C₂-valued cycle: two equality edges and one flip give holonomy with no fixed bit. The lawful map sends a pair relation to its bijective transport graph, (u,v)∈R_e iff v=g_e(u). This works only when each relation is the graph of a bijection; arbitrary constraints need a relation-valued groupoid replacement.
