# SWM-A04 — Nonabelian obstruction lives in the actual action

## 1. Original question
Which graph transport invariants obstruct a path-blind global section, and which survive gauge changes?

## 2. Existing mathematical context

## 3. Proposed SUCC objects
A complete finite connected graph G has fiber F={0,…,d−1} and invertible edge maps g_e:F→F; reverse edges use inverses. Choose a root and spanning-tree transports P_v from root to vertex v. Each non-tree or redundant edge has based holonomy H_e=P_v⁻¹g_eP_u. A section is s_v with s_v=g_es_u on every source edge. A gauge k_v changes g_e to k_vg_ek_u⁻¹.

## 4. Candidate theorem
Root values of global parallel sections are exactly ⋂_e Fix(H_e), and section propagation s_v=P_vx is a bijection from that set to all global sections. Under gauge, sections transform by s'_v=k_vs_v and based holonomy by conjugation with k_root. A target descends to the holonomy-orbit quotient iff it is constant on every orbit.

## 5. Proof attempt — complete local derivation
Tree equations uniquely force s_v=P_vs_root. Substituting into an arbitrary edge equation gives P_vs_root=g_eP_us_root, equivalent to H_es_root=s_root. This proves necessity and sufficiency for all edges. Substituting k_v into each equation proves gauge invariance; tree products telescope to P'_v=k_vP_vk_root⁻¹, yielding H'_e=k_rootH_ek_root⁻¹. Orbit-invariant targets define an unambiguous quotient decoder; unequal values in a single orbit give an immediate collision witness.

A nontrivial permutation holonomy may fix some fiber values, so existence of a section does not imply flatness. For a **regular group torsor** action, a nonidentity group element fixes no point, and global sections require identity holonomy. These two source types must remain distinct.

## 6. Crucible
All **216 S₃ triangle connections** are compared with independent brute-force enumeration of all 27 sections. The same 216 connections undergo vertexwise noncommuting gauge mutation and produce precisely the transformed section sets. The even 3-cycle (0→1→2→0) has trivial sign image but no fixed point; abelian parity therefore misses the obstruction. Replacing it by identity gives three sections. Omitting its edge while retaining the declared source edge list is rejected.

On the universal covering tree, any root value propagates to a section because no loops impose extra equations. It descends to the original graph exactly when deck/loop transport fixes it. Upstairs existence is therefore not a downstairs certificate.
