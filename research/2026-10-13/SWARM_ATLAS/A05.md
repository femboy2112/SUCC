# SWM-A05 — Kan extension exists; source information does not appear

## 1. Original question
Can changing an observation language universally extend a model while retaining source meaning?

## 2. Existing mathematical context
Source-typed model capsules in `categorical_model_bridges.py` have explicit all-frequency and composition gates. The pointwise formulas for Kan extensions are classical: [Riehl, Category Theory in Context](https://emilyriehl.github.io/files/context.pdf), Theorem 6.2.1 and Corollary 6.2.9. The general Set-valued extension theorem has smallness and (co)completeness hypotheses; the implemented case is finite discrete language categories.

## 3. Proposed SUCC objects
A language migration is a map f:O→P between finite discrete categories. A model M:O→Set assigns an exact finite candidate set M_o to each old report. Left/right extension values are respectively L_p=⨿_{f(o)=p} M_o and R_p=∏_{f(o)=p} M_o. Tagged sums preserve which old report supplied a candidate; product coordinates preserve simultaneous choices.

## 4. Candidate theorem
There are canonical natural bijections Nat(L,N)≅Nat(M,Nf) and Nat(N,R)≅Nat(Nf,M). At a new label outside f(O), L is empty while R contains the empty tuple. These universal objects do not imply a decoder from a coarse source report to a genuinely finer source report.

## 5. Proof attempt — complete finite derivation
A map L_p→N_p is uniquely the family of maps M_o→N_p for f(o)=p, by evaluating each tag. Conversely assemble those maps on tagged pairs (o,m). This constructs inverse bijections, proving the left extension law. A map N_p→R_p is uniquely its coordinate maps N_p→M_o; combine them into a tuple. These are inverse constructions, proving the right law. Empty sums/products give the displayed boundary values.

For the source obstruction, take X={0,1}, old q=(0,0) and new r=(0,1). A decoder d:{0}→{0,1} would need d(0)=0 and d(0)=1. None exists. This is a source-map obstruction, even though formal Kan extensions of the coarse model exist.

## 6. Crucible
For f=(0,0), M₀={10,11}, M₁={20}, the exact implementation returns three tagged sum elements and two product elements at label 0. Into a two-element test set the left universal correspondence has 2³=2²·2¹=8 maps; the right counterpart has 2²=2²·1²=4 maps. Label 1 has empty left fiber and one empty product tuple. Missing model fibers and out-of-domain migration labels are rejected. Exhaustive two candidate coarse-to-fine decoders confirms the source collision.

## 7. Verdict
**CLASSICAL.** Finite discrete Kan formulas with source-invention counterexample. “Universal representation migration automatically recovers finer source information” is **REFUTED**.

## 8. Remaining obstruction
For the full causal-history category, one must provide a lawful functor on paths and report maps before a Kan extension can be interpreted as a source model. The next lemma is a source-realizability comparison from the extension object to actual lawful histories, specifying when it is bijective. Products of alternative-source fibers generally do not represent one possible source.
