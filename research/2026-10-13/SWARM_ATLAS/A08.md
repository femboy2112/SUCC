# SWM-A08 — Resource paths enrich; raw separation debt does not

## 1. Original question
Which observation costs can be enriched hom-values, and when does a source-faithful report map contract them?

## 2. Existing mathematical context

## 3. Proposed SUCC objects
A full resource state is a vertex in a finite directed graph with nonnegative exact rational edge costs. D(x,y) is infimum path cost, ∞ for no path and 0 for the empty path. Separately, for a complete deterministic source define k(x,y) as minimum probe count of a generated word ending in unequal reports, with the present report costing one and each action one extra. Set d(x,y)=0 if no word separates them, otherwise 2^{−(k−1)}.

## 4. Candidate theorem
D satisfies Lawvere's directed extended triangle law. Any functor taking every source edge to a target path of no greater cost contracts D. The raw distinguishability cost k is not a distance. Its exponential **inverse** d is a pseudoultrametric, descending to a metric on the behavioral quotient. Same-action report coarsening contracts d; exact action/report intertwining preserves d on mapped state pairs.

## 5. Proof attempt — direct derivation
Concatenate x→y and y→z paths. Their costs add, so taking infima gives D(x,z)≤D(x,y)+D(y,z); absence of paths obeys the extended-real convention. Map a near-optimal path through a cost-nonincreasing functor to prove contraction. The empty path supplies D(x,x)=0. Hidden state-dependent fees require including that state in the vertex before path concatenation is valid.

For observational d, let E_m mean agreement after every action word of length at most m. Each E_m is an equivalence and E_{m+1}⊆E_m. If x,y and y,z agree through level m, then so do x,z, by equality of every word report. Thus first-separation levels satisfy k(x,z)≥min(k(x,y),k(y,z)), with ∞ for equivalence, giving d(x,z)≤max(d(x,y),d(y,z)). Report coarsening can postpone a first distinction but cannot create an earlier one; hence d contracts. Strict report-preserving source intertwining gives identical word reports and equal d.

## 6. Crucible
A five-state source has reports (0,0,1,0,0) and transition (0,3,2,4,2). It gives k(0,1)=4 while k(0,2)=k(1,2)=1: **4>1+1**. Raw separation debt also has infinite diagonal, so it already fails the identity law. The derived d passes all 125 triples for this hostile source. Exact rational path costs 1/3 then 2/3 beat a direct cost 5 and give D(0,2)=1; all 27 directed triangles pass. Negative fees and uncertified float costs are rejected.

## 7. Verdict
**REFUTED** for raw distinguishability debt as a Lawvere distance. The repaired shortest-path geometry and observational pseudoultrametric are **CLASSICAL**, with local derivations and exact controls. No universal physics or thermodynamic cost law follows.

## 8. Remaining obstruction
State-dependent availability, destructive actions and budget resets can invalidate a cost map on compressed observer states. The next lemma should identify a sufficient retained-resource carrier on which the original transition cost is additive and the chosen quotient is cost-nonincreasing. Metric completeness is a further topological issue, not implied by finite repair.

## 9. Cross-domain connection

Resource geometry transfers optimal proof-policy costs only when the policy correspondence preserves available actions and their costs, not merely report equivalence.
