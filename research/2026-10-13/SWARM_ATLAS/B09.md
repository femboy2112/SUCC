## 3. Proposed SUCC objects

Let `S`, `W`, and `O` be arbitrary mathematical sets/types and let `trace : S → W → O`. For the deterministic source model, `W=A*`, `trace(s)(w)=q(U_w(s))`. No reset access is implied by listing counterfactual words.

For each finite probe family `F`, define

\[
X_F=\{r:F\to O\mid \exists s\in S\;\forall w\in F,\ r(w)=\operatorname{trace}(s)(w)\}.
\]

For `F⊆G`, the restriction `r_GF:X_G→X_F` forgets coordinates. The inverse-family object consists of an element `x_F∈X_F` for **every** finite family and equations `r_GF(x_G)=x_F`. Thus shared-source local compatibility and cross-stage coherence are part of the actual type.

The Lean realization uses all finite lists, ordered by inclusion of underlying probe membership. Coordinates have type `{w // w ∈ F} → O`, so permutations and duplicate probe names cannot create independent values. The empty list is included: its stage is inhabited exactly when `S` is inhabited. This handles `S=∅`, including `W=∅`, without adding a phantom original source.

Define

\[
Z=\{z:W\to O\mid\forall F\text{ finite}\;\exists s_F\in S\;\forall w\in F,\operatorname{trace}(s_F)(w)=z(w)\}.
\]

This is an ideal mathematical profile space. The witnesses `s_F` may vary with `F`. Topological claims give `O` the discrete topology and `O^W` the product topology. ## 5. Proof attempts and surviving derivations

**Actual inverse families.** For `x=(x_F)`, set `d(x)(w)=x_{\{w\}}(w)`. The coherence equation for `{w}⊆F` gives `x_F(w)=d(x)(w)`. Since `x_F∈X_F`, an original state realizes `d(x)` on `F`; hence `d(x)∈Z`. Conversely, set `e(z)_F=z|F`. Finite compatibility places it in `X_F`; restrictions commute. The singleton and all-stage equations give `d(e(z))=z` and `e(d(x))=x`. These are the two Lean inverse equations, not just an assertion that some bijection should exist.

**Stage surjectivity.** For `x_F`, choose its already supplied source witness `s`. Then `trace(s)|G` restricts to `x_F`. This is local elimination of an existential inside the proof; no global choice of `s_F` is required to construct `e(z)`, since its coordinates are directly `z|F`.

**Cofinal schedule.** If `G_k` contains every finite family inside some stage, a stage witness for `G_k` is a witness for the smaller `F`. The reverse direction is immediate. Mere singleton coverage fails by the two-source example in §6.

**Closure identification (subsequently kernel-checked).** For discrete `O`, finite equality cylinders

\[
C_F(z)=\{y\in O^W\mid y|F=z|F\}
\]

form a neighborhood basis at `z`. Consequently `z∈closure(trace(S))` iff every `C_F(z)` meets the trace image, exactly the defining condition of `Z`. The map `d` is continuous because each `w` coordinate is singleton projection from the inverse-family product. The map `e` is continuous because each finite-stage coordinate is finite-coordinate restriction from `O^W`. Their inverse equations therefore yield a **homeomorphism** with the subspace `Z`, not merely a bijection. The actual image is dense by the defining closure equality. Empty images are handled without assuming the limit nonempty.

**Actualization (subsequently kernel-checked).** Under the preceding identification, the map `S→lim X_F` has image `trace(S)`. It is surjective exactly when `trace(S)=closure(trace(S))`, equivalent to closedness. If `S` is compact and every coordinate report is continuous, the product trace map is continuous; its image is compact, and the product of discrete spaces is Hausdorff, so the image is closed. This source-sufficiency theorem works even for infinite discrete `O`; alphabet finiteness is not needed when source compactness is independently known.

**Exact compactness/profinite criterion.** Put `K_w={trace(s)(w):s∈S}`. If every `K_w` is finite, `closure(trace(S))⊆∏_w K_w`, since each coordinate-value set is closed in discrete `O`. The right side is compact by Tychonoff. The closure is closed in that product, hence compact; it is Hausdorff and zero-dimensional, thus profinite. Conversely, if the closure is compact, each coordinate projection of it is compact in a discrete space and therefore finite, so its subset `K_w` is finite. For `W=∅`, the ambient space is a singleton; both possible closures are compact and the coordinate condition is vacuous. The exact compactness equivalence is kernel-checked using mathlib's native compactness. The extra zero-dimensionality/profinite interpretation is a classical consequence; this file does not construct mathlib's bundled `Profinite` category object or a zero-dimensionality instance.

**Lawful update extension.** Given the displayed action square, a finite family `F` for `z∘r` corresponds to `r(F)` for `z`. A witness `s` there gives the lawful witness `U(s)` here. Lean proves this general reindexing theorem. Topologically, each reindexing `z↦z∘r` is continuous, so it extends the original source action to its profile closure. For words, `r_a(w)=aw`; the original trace derivative gives the required square. The ideal action does not imply the existence of an original source for an added ideal profile.

**Compact positive control.** Let `S={0,1}^N` with the Cantor topology, lawful shift, and `q(x)=x(0) xor x(1)`. The full future trace is `D(x)(n)=x(n) xor x(n+1)`. For arbitrary `z`, set `I(z)(0)=0` and `I(z)(n+1)=I(z)(n) xor z(n)`. The Boolean identity `a xor (a xor b)=b` proves `D(I(z))=z`. This is kernel-checked. The native topology file separately proves derivative continuity and applies the general compact-source theorem, using mathlib's product compactness instance, to this genuinely infinite source. The two possible preparations `I(z)` and its global complement show that actualization does not imply recovered source identity; this final two-preparation observation is paper-level, rather than another advertised kernel lemma.
