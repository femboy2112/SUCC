## Exact objects and quantified theorem

Let S,W,O be arbitrary types, O equipped with its discrete topology, and
trace:S->(W->O). In SUCC, W can be all lawful finite action words and
trace(s)(w)=q(U_w(s)); no topology or finiteness on S is needed for the first
results. Define finite compatibility of z by

`forall F:Finset W, exists s:S, forall n∈F, trace(s)(n)=z(n)`.

For every finite F define X_F as the restrictions of actual traces to F.
For F⊆G the transition X_G->X_F is ordinary restriction. An inverse thread
has one source-admissible row z_F:F->O for every finite F, with rows agreeing
on overlapping coordinates. The thread type is a subtype of the dependent
product `forall F:Finset W, F->O`, with actual product/subspace topology.

**Kernel statements.**

1. `closure_iff_finite_compatible`: z belongs to the product-topology closure
   of range(trace) iff z is finite-compatible, for arbitrary discrete O.
2. `all_compatible_realized_iff_closed_image`: every finite-compatible z has
   an original source realizer iff range(trace) is closed.
3. `profileToThread`, `threadToProfile` are mutually inverse **continuous**
   maps between finite-compatible profiles and inverse threads. The theorem
   `inverse_limit_completion_topological_equivalence` packages the four
   homeomorphism obligations explicitly. `completion_eq_closure` identifies
   the profile space with the literal product closure, not a software flag.
4. For finite O, `finite_alphabet_completion_compact` proves that closed
   observational completion is compact using the actual Pi/Tychonoff instance.
5. `compact_continuous_source_realizes`: if S is a compact topological space
   and each coordinate report trace(-)(n) is continuous, every finite-compatible
   profile is realized by one original S state.

The formalization packages the homeomorphism as explicit continuous inverse
maps rather than importing an extra named `Homeomorph` wrapper. All its
mathematical obligations are checked. The compact-source theorem does not
need finite O, only discrete O; finite O is used for compactness of the whole
completed profile space.

## Proof and formal maps

For closure -> finite compatibility, the cylinder specifying z at F is open,
contains z, and therefore intersects the source trace image. For the converse,
a product-open neighborhood contains a basic finite-coordinate neighborhood;
finite compatibility supplies one actual source trace inside it.
Closedness is exactly closure=image, giving universal actualization iff closed.
For compact S the coordinate-continuous trace is continuous by `continuous_pi`;
its image is compact and hence closed in the Hausdorff discrete product.

A profile maps to its finite restrictions. A thread maps to the profile
whose n-th coordinate is the singleton row z_{ {n} }(n). Coherence equates
this singleton value with every row containing n; admissibility then proves
finite compatibility. Singleton evaluation proves one inverse identity and
overlap coherence proves the other. Coordinate evaluations are continuous;
`continuous_pi` twice and subtype continuity prove both maps continuous.
These are actual functions with checked inverse laws, not suggestive diagrams.
