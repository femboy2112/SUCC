# SWM-B11 — Effective finite refutation

## 1. Original question

Does a complete finite ORIGINAL-source enumeration turn classical finite-refutation
existence into an effective search, a total decision, or a cost bound? Parent:
`5eb09e7cba36ec01b8f9d6834b78b5766fd93935`; isolated branch

## 2. Existing mathematical context

Voyager V3/O616 proves a classical dichotomy for arbitrary contexts using
`Classical.choose`; O638 rejects an automatic algorithm/cost inference. Existing
F4/O417 already reduces two-state probe sufficiency to halting. B11 supplies the
positive effective repair and a singleton profile-refutation reduction, without
claiming academic novelty.

[Turing, §1 and §8, pp. 231–232, 248](https://www.cs.virginia.edu/~robins/Turing_Paper_1936.pdf)
distinguishes finite control from its tape and proves the printing problem
undecidable. Halting reduces to printing by replacing HALT with printing a
designated symbol. [Dudenhefner, Definition 2 and Theorem 6](https://doi.org/10.4230/LIPIcs.FSCD.2022.16)
provides an instruction-sensitive counter-machine comparison. The universal
reduction below uses arbitrary Turing programs; bounded repository fixtures are
not a universal-machine certification.

## 3. Proposed SUCC objects

For each effectively presented instance e, supply an exhaustive finite list
S_e=(s_1,…,s_N), an authorized context set W_e with computable surjection
p_e:ℕ→W_e, and total uniformly computable reports r_e(s,w) and target z_e(w)
in an exactly encoded alphabet with decidable equality. Completeness,
authorization and totality are premises, not inferred from successful samples.
Put D_e(s,n) ≡ r_e(s,p_e(n))≠z_e(p_e(n)). A certificate is at most N
contexts covering every source by a mismatch. Contexts may be arbitrary programs;
N does not bound their lengths, their enumeration indices, or evaluation costs.

## 4. Candidate theorem

**B11-E, CLASSICAL / PROVED LOCAL:** one uniform partial algorithm returns an
exact certificate iff no s∈S_e realizes z_e on every context. Under an
unrealizability promise it terminates on every admitted instance. These
effectiveness assumptions suffice; they are not asserted individually necessary.
Uniformly semidecidable mismatch also suffices by dovetailing.

**B11-T, REFUTED:** replacing partial search with a total selector, or assigning
a total computable witness-time bound from arbitrary effective descriptions.

## 5. Proof attempt

At stage n evaluate D_e(s,n) for every surviving source; retain a source's first
mismatch and remove it. Halt when none survive. Soundness follows by replaying
each retained mismatch. If no source realizes the target, each of the finitely
many sources has some witnessing index n_s; stage max_s n_s removes them all.
If a realizer exists it survives every stage, so the algorithm never returns.
Duplicates in p_e cause no difficulty. For an empty source list, the empty
certificate returns immediately. For semidecidable D, dovetail all (s,n)
recognizers rather than blocking on a nonmismatch. Thus the exact halting domain
is the unrealizable-instance set, which is computably enumerable under these
presentation hypotheses. Finite evaluations supply no computable maximum n_s.

## 6. Crucible

Take the smallest nonempty source S={s}, W=ℕ, r(s,n)=0, and
z_e(n)=H_e(n), where H_e(n) is the decidable indicator that program e halts
within n steps. Then z_e is unrealizable iff e halts. Every refutation has
cardinality one. Suppose a total computable selector f(e) returns a valid
witness whenever one exists; allow arbitrary outputs otherwise. Then
e halts iff H_e(f(e))=1, a total halting decision, contradiction. A computable
bound B(e) on the least witness for halting e yields the identical contradiction.
A total finite-list selector reduces to this case by taking its maximum,
using zero for an empty list. A total runtime bound for the partial search
would likewise decide whether it halts. This refutes total extensions; it does
not refute promised partial extraction.

The fixed one-state stationary zero carrier realizes r. Its target evaluator
uses an external bounded simulation at each n. With delay d, the first mismatch
is d despite source cardinality one. The receipt uses d=0,7,37,71, a known loop,
and an independent bounded recurrence; it illustrates the reduction, not its
universal undecidability proof.

## 7. Verdict

**SURVIVES:** B11-E with explicit effectiveness and exhaustive-source premises.
**FAILS:** B11-T with the complete halting reduction as receipt. The finite
certificate theorem remains valid. Sharp three-source controls require three
different contexts; omitted-source and forged-witness controls fail replay.
κ is exact declared-model access; φ is finite-prefix agreement; σ remains
conditional on the source presentation; no ρ/identity coupling is inferred.

## 8. Remaining obstruction

A finite ORIGINAL candidate list permits arbitrarily complicated context/target
programs. A finite stationary CURRENT carrier is a stronger transition-law
hypothesis but still does not constrain an arbitrary external target. Neither
certificate cardinality nor autonomous controller state count bounds search
workspace or elapsed computation. Symbolic evaluation also does not license
physically executing destructive branches: reset/copy access, calibration and
per-action costs require separate premises. The next falsifier is a proposed
algorithm that quietly assumes one of these premises from metadata.

## 9. Cross-domain connection with actual maps

There is a bounded automata repair. Supply finite total stationary machines
(C,U_a,q) and (T,V_a,h,t_0) on the same finite alphabet, with
z(w)=h(V_w(t_0)) and original sources in C. The synchronized map is
P_a(c,t)=(U_a(c),V_a(t)); a bad pair satisfies q(c)≠h(t). Breadth-first
search reaches every pair reachable from (s,t_0). A shortest bad path repeats
no pair, hence has length ≤|C||T|−1. If none is reachable, every word matches,
giving a total realization decision. Collect one path per nonrealizing original
source. The unary receipt attains the bound: |C|=1, |T|=38, first mismatch 37.
This word bound becomes a physical cost bound only with supplied action costs.
