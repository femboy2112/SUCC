# SWM-B11 — Effective finite refutation, and the missing uniform horizon

## Original question and existing mathematical context

VOYAGER's finite-source Lean theorem uses `Classical.choose` to select a
mismatch for each source. What extra hypotheses permit effective extraction,
and which resource conclusions remain false even for one source state?
Existing context: computable enumeration, semidecision, and the halting problem.
Primary historical source: Turing, *Systems of logic based on ordinals* (1939),
https://doi.org/10.1112/plms/s2-45.1.161 ; archive receipt:
https://turingarchive.kings.cam.ac.uk/publications-lectures-and-talks-amtb/amt-b-15 .
The modern halting undecidability argument below is supplied in full, rather
than attributed to an unchecked theorem statement in that archive metadata.

## Objects, access contract, and theorem

S={s_1,...,s_N} is a **complete** finite source enumeration. W has a computable
surjection e:N->W. Both trace(s_i,e(n)) and target(e(n)) are uniformly total
computable values in a report type with decidable equality. Reports concern
counterfactual mathematical experiments; physical replay/reset is a separate
assumption. Define mismatch M_i(n) iff the two outputs differ.

**Theorem.** Dovetail testing n=0,1,... against every still-live source,
retaining its first mismatch, terminates iff no original s_i realizes the
whole target. At termination a refutation has at most N retained probes and
at most one retained witness per source. On a finite exhausted enumeration
the only sound verdict without a global-law certificate is UNRESOLVED.

## Proof

If no source realizes the target, each i has a mismatch probe, and complete
surjectivity supplies an index n_i. Since S is finite, max_i n_i is finite.
Every i is removed by that point. Conversely, if the algorithm removes all i,
its retained mismatch proves each source fails the target; no whole-profile
realizer exists. A source satisfying every probe is never removed. Each
removed source receives exactly one witness; duplicate retained probes may
refute several sources, so the number of distinct probes is <=N.
This constructive procedure requires no decision of universal agreement.

## Sharp no-go: no total computable uniform search horizon

For each encoded program e, construct the uniformly computable target
`t_e(n)=1` iff e halts within n steps, and zero otherwise. Take the **one-state**
source with constant zero output. A mismatch exists iff e halts. Suppose a
total computable b(e) bounds a first mismatch whenever a mismatch exists.
Compute b(e), simulate e for b(e) steps, and answer HALTS exactly when seen.
The bound's conditional correctness would decide halting, contradiction.
The source cardinal N=1 and a finite certificate do not bound witness time.
A partial procedure that halts only on refutable instances is allowed and is
exactly the semidecision above. This is a domain/access distinction, not a
claim about a particular fixed problem or RH.

If equality/report access is not computable, even uniform extraction need
not exist: let a singleton-source target have its unique mismatch at coordinate
0 when e does not halt and at coordinate 1 when it does halt. Every instance
has a one-probe certificate; a uniform selector would decide halting. This
example deliberately lacks effective target evaluation and cannot be run by
a program. It calibrates which hypothesis the constructive theorem needs.

## Crucible

The implementation retains witnesses, then a separate replay verifies them.
Thirteen declared sources first mismatch at coordinates 0,7,...,84: search
through 84 refutes, while exhaustion through 79 stays UNRESOLVED with source
12 remaining. A forged receipt using only coordinate 1 fails verification.
A genuine known loop remains unresolved through 200 simulated steps;
delayed-halt programs with delays 0,1,7,55 refute when the first halt becomes
visible. These finite controls validate the reduction mechanism, not the
universal undecidability theorem. An empty source has a vacuous empty
refutation. An incomplete source enumeration falsifies the semantic use of
the certificate even though witness replay against its listed entries passes.

## Remaining obstruction and cross-domain bridge

There are two different debts: N retained proof witnesses and the maximum
witness address/time. The map to B16 sends source alternatives to their
behavioral residual traces; a small residual count does not bound a target's
first disagreement. The map to B13 sends discovered mismatches to finite
axiom support. Finite support supplies a stage *after* discovery, not a
computable bound *before* it. Next lamp: add a source-specific algebraic law
that produces a computable disagreement bound, then independently test that
law rather than reading it off finite cardinality.
