## 3. Proposed SUCC objects

Let (X=2^{\mathbb N}), with discrete bits, and (S\subseteq X) any declared source contract. Retained report (r_n(x)=x|n) determines cylinder ([u]_S=S\cap\{x:x|{|u|}=u\}). A stopping policy labels prefixes with `yes`, `no`, or `continue`, using no source-description oracle. A label is sound only when its whole relative cylinder has that label. Define on (X):

\[
E=\{x:\exists N\ \forall n\ge N\ x_n=0\},\quad
I=\{x:\forall N\ \exists n\ge N\ x_n=1\}=X\setminus E,
\]
\[
P=\{x:\exists N\ \exists p\ge1\ \forall n\ge N\ x_n=x_{n+p}\}.
\]

## 4. Candidate theorem

**CLASSICAL, paper derivations below.** For every (S\subseteq X,A\subseteq S):

- A sound policy terminates with the correct yes/no answer on every (x\in S) iff (A) is relatively clopen.
- A uniform observation horizon exists iff (\exists N\ \forall x,y\in S: r_N(x)=r_N(y)\Rightarrow\mathbf1_A(x)=\mathbf1_A(y)).
- Sound positive recognition, terminating exactly on (A), exists topologically iff (A) is relatively open; negative recognition iff (S\setminus A) is relatively open.

For compact (S), the first two conditions coincide. Without compactness they can differ. These existence statements permit noncomputable policies. Under the ordinary bit-oracle representation, computable positive recognition requires a computably enumerable prefix family (W) with (A=\bigcup_{u\in W}[u]_S); two such families for complementary answers give effective decision by dovetailing.

## 5. Proof attempt

A terminating output uses a finite prefix; all sources sharing it receive the same answer. Thus each answer fiber is open. Conversely, relative openness supplies a sound prefix around each appropriate source: stop at the first homogeneous prefix. A uniform horizon is exactly constancy on depth-(N) cylinders. Compactness gives a finite subcover of homogeneous cylinders; their maximum depth supplies (N). Effective accepting computations enumerate accepting cylinders; conversely, enumerate cylinders while reading bits and halt on a match. The one-sided proof uses only the accepting fiber.

For Borel upper bounds,
\[
E=\bigcup_N\bigcap_{n\ge N}\{x:x_n=0\},\qquad
P=\bigcup_{N\ge0,\,p\ge1}\bigcap_{n\ge N}\{x:x_n=x_{n+p}\}.
\]
Each inner intersection is closed and finite, hence (E,P\in\boldsymbol\Sigma^0_2), while (I\in\boldsymbol\Pi^0_2). Both (E,P) are countable dense meagre sets. A dense (G_\delta) is comeagre, contradicting Baire if also meagre. Therefore (E,P\notin\boldsymbol\Pi^0_2) and (I\notin\boldsymbol\Sigma^0_2): exact classes.

Completeness has actual maps. For any (B=\bigcup_j C_j\subseteq2^{\mathbb N}) with increasing closed (C_j), set
\[
k_s(x)=\min\bigl(\{j\le s:[x|s]\cap C_j\ne\varnothing\}\cup\{s+1\}\bigr),
\quad f(x)_s=\mathbf1_{k_{s+1}(x)>k_s(x)}.
\]
The integer sequence is nondecreasing. It is bounded exactly when (x\in B): membership in some (C_j) bounds it; outside every closed (C_j), sufficiently long prefixes avoid each fixed (C_j). Thus (x\in B\iff f(x)\in E). Each output bit depends on a finite prefix, proving continuity. The same argument works for Baire-space inputs. Consequently (E) is (\boldsymbol\Sigma^0_2)-complete and (I) is (\boldsymbol\Pi^0_2)-complete under these continuous reductions.

Finally (g(x)=x_0 0^1 x_1 0^2 x_2 0^3\cdots) is continuous. Finite input ones give an eventually zero output. Infinitely many give infinitely many output ones with arbitrarily long intervening zero runs. An eventually periodic tail containing ones has bounded zero runs. Hence (g^{-1}(P)=E), proving (P)'s (\boldsymbol\Sigma^0_2)-completeness in the same domain scope.

## 6. Crucible
