## Original question and literature

Classify eventual-zero, infinitely-many-ones, and eventual-periodicity by their
finite-cylinder and Borel structure. Which source properties are finitely
identifiable at every individual stream? Background: Kechris,
*Classical Descriptive Set Theory* (1995),
https://doi.org/10.1007/978-1-4612-4190-4 ; author/publisher chapter inventory
was read, with exact arguments provided below. These are classical examples,
not claims of a new descriptive-set hierarchy or logical independence.

## Source, instruments, and candidate theorem

Let X⊆O^N carry its subspace product topology, O finite discrete, and P⊆X.
A property has a pointwise finite observational certificate if

`forall x∈X, exists finite F⊆N, forall y∈X,
  (forall n∈F, y(n)=x(n)) -> (y∈P iff x∈P)`.

**Theorem.** This certificate condition holds iff P is clopen in X. If X is
compact, the equivalent condition is a uniform finite-coordinate truth table:
there is one finite F that decides P for **every** x∈X. For W=N, a uniform
finite F is contained in one finite initial horizon.
This is mathematical finite-coordinate definability. To be an effective
algorithm the truth table and query access must also be supplied. To be an
executable single history the instruments must permit these queries jointly.

## Proof

A certificate cylinder around a positive x lies in P and around a negative x
lies in X\P. Union the positive cylinders to obtain openness of P and union
the negative ones to obtain openness of its complement. Conversely a clopen
set and its complement supply cylinder neighborhoods at every point.
If X is compact, take the finite subcover from these certificate cylinders,
and let F be the union of their finite address sets. If x and y agree on F,
choose a covering cylinder containing x; y belongs to it too, so they have
the same property value. The reverse implication is immediate since each
fiber of restriction to finite F is clopen and there are finitely many values.
The compactness step is classical; it supplies neither a constructive bound
nor a non-reset physical policy. The root's causal-policy investigation owns
that separate distinction.

## Borel classification on full binary Cantor space

| Property | Exact descriptive level | Finite-coordinate certificates |
|---|---|---|
| Eventually zero | Σ⁰₂ (Fσ), not Π⁰₂ (Gδ) | Neither membership nor nonmembership at any point |
| Infinitely many ones | Π⁰₂ (Gδ), not Σ⁰₂ (Fσ) | Neither membership nor nonmembership at any point |
| Ultimately periodic | Σ⁰₂ (Fσ), not Π⁰₂ (Gδ) | Neither membership nor nonmembership at any point |
| Fixed coordinate value x(7)=1 | Clopen, Δ⁰₁ | One exact probe |

Eventually zero is union_N intersection_(n≥N){x(n)=0}; each inner set is
closed nowhere dense. It is countable, dense, and meagre. If it were Gδ,
its expression as a dense Gδ would make it comeagre in the Baire Cantor
space, contradicting meagreness. Infinitely many ones is its complement,
intersection_N union_(n≥N){x(n)=1}; complementing the strict result gives
its exact Π⁰₂\Σ⁰₂ level.
Ultimately periodic is union_(N,p≥1) intersection_(n≥N){x(n+p)=x(n)}.
Each fixed N,p set is finite (the first N+p bits determine everything),
closed and nowhere dense. Their union is countable, dense, meagre, and
cannot be Gδ by the same Baire argument. These show strict levels; no
Σ⁰₂-completeness under continuous reductions is claimed or needed.

## Adversarial witnesses

For any finite transcript, the zero-tail completion is eventually zero,
ultimately periodic, and has only finitely many ones. The one-tail completion
is not eventually zero and has infinitely many ones. A sufficiently late
power-of-two marker completion matches the transcript but is not ultimately
periodic: its infinitely many marker gaps are unbounded, whereas an eventually
periodic binary stream with infinitely many ones has bounded marker gaps.
Hence every cylinder intersects each property and its complement.
The implementation tests 150 independent scattered address families, not only
prefixes. `power_marker_patch` rejects coincident marker/default symbols;
without that assumption the purported nonperiodic construction collapses.

Removing compactness kills the uniform conclusion: take X to be streams with
exactly one 1. P is membership where the 1 is at an even index; every point
has a one-probe certificate at its marker, so P is clopen relative to X.
No finite common coordinate set decides parity of an arbitrarily remote
marker. This is a source promise, not a full-Cantor classifier.

## Remaining obstruction and bridge

Changing permitted probes changes the topology and therefore clopenness.
A global-law formula can decide a property where raw coordinates cannot;
that is a different instrument/language, not a counterexample to the theorem.
B12's partial-map cylinders supply the certificate supports. B10 controls
which compatible complete profiles belong to the actual source. B11 asks
whether the classical finite cover/truth table can be computed from the
source presentation. Those three requirements are distinct.
