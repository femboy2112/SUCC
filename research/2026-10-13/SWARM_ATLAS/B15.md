## Objects and quantified theorem

Fix action set A and report set O. A deterministic Moore source is a coalgebra
for F(X)=O×X^A: c(s)=(q(s),(a↦U_a(s))). Let Z=O^(A*) with
head(z)=z(empty) and derivative D_a(z)(w)=z(a::w).
For every source c there is exactly one coalgebra morphism
`beh_c:S->Z`, namely `beh_c(s)(w)=q(U_w(s))`.
Its kernel is the greatest report-preserving equivalence invariant under
all actions. The image quotient is the minimal behaviorally faithful source;
for finite S it has exactly the number of distinct all-word behavior classes.

## Proof and minimality

The empty word gives report preservation. Prefixing a gives
`beh(U_a(s))(w)=beh(s)(a::w)`, so the action squares commute.
If h:S->Z is any coalgebra morphism, induction on the word proves h(s)(w)
is the same report trace: use the head square at the empty word, and the
derivative square plus induction at a::w. Thus h=beh by function extensionality.
Equality of all-word behaviors is report-preserving and action-invariant.
Any report-preserving action congruence implies equality along every finite
word by induction, so it is contained in the kernel.
Define the quotient transitions [s]↦[U_a(s)]; kernel invariance makes these
well-defined. Its report is q(s), also well-defined. The quotient embeds
injectively into Z. Any behavior-preserving source representation identifies
only kernel-equivalent states, so it needs at least as many states; the
quotient attains that number. This is classical Moore/Nerode minimization.

## Exact multi-action crucible

`MooreSource.separator(s,t)` does BFS on reachable state pairs and returns a
shortest distinguishing future word, or None if their full behaviors agree.
A separate partition-refinement implementation independently computes the
kernel on120 seeded complete sources with two actions and up to9 states.
The quotient replays every word through length3 from every source state;
report/action squares are asserted, not inferred from labels.
A three-state source with reports (0,0,1) and transitions (0→0,1→2,2→2)
shows same current report does not imply final behavior equality: action a
separates0 and1. Missing actions changes the kernel and semantic conclusion.
A separator is a counterfactual future experiment; physical execution on one
carrier or access to both preparations is not automatically licensed.

## Why relational and stochastic trace equality are different

For nondeterministic labeled systems, trace equivalence can be weaker than
bisimulation. State s has a-transition to either a b-only branch or a c-only
branch; state t has a-transition to one branch offering both b and c. Both
have traces {empty,a,ab,ac} (and corresponding prefixes), but no bisimulation
can match either s-successor with t's successor, which has an extra action.
Thus merely replacing deterministic transitions by support sets changes the
semantic invariant; powerset-coalgebra bisimulation does not collapse to this
trace language without a justified determinization construction.

For stochastic reports, Bernoulli(1/4) and Bernoulli(3/4) have identical
support {0,1} and different laws. Support equality is not distributional
behavioral equality. For history dependence, a present-state-only quotient
can erase the information needed by future responses; unfold the state to
(include original preparation, current carrier, causal history) and only
then apply deterministic or probabilistic semantics appropriate to that type.
No existence theorem for an arbitrary stochastic final coalgebra is claimed.
