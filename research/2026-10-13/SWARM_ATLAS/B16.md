## Source model and sharp theorem

A stationary autonomous Moore source has a nonempty finite set S, fixed
successor U:S->S, report q:S->O, and initial state s_0. Source-state count is
|S|, not program-size, observer memory, counter storage, or energy. The source
must reproduce an observed word w=(w_0,...,w_(L-1)) exactly. O is an arbitrary
finite alphabet, or the finite set of symbols actually appearing in w.

For L>0 define

    m(w) = min {mu+p : 0<=mu, 1<=p, mu+p<=L,
                 forall t with mu+p<=t<L, w_t=w_(t-p)}.

**Theorem.** The minimum number of stationary deterministic source states
realizing w is exactly m(w). For the empty word, a nonempty source needs1
state, while no observation imposes any other constraint.

## Complete proof

**Upper bound.** For an admissible(mu,p), use states0,...,mu+p-1, report w_i
at state i, successor i↦i+1 below the last state, and last↦mu. Its orbit emits
the finite prefix w_0,...,w_(mu-1) followed by the cycle
w_mu,...,w_(mu+p-1). The consistency equalities imply, by repeatedly
subtracting p, that every observed later w_t agrees. This constructs exactly
mu+p states. The pair(mu=L-1,p=1) always exists, giving the trivialL bound.

**Lower bound.** Follow any source orbit through theL observed states. If no
state repeats, it has at leastL≥m(w) states. Otherwise let j<L be its first
repeat index, with state_j=state_i for unique i<j. Thej states before j are
pairwise distinct by first-repeat minimality, so |S|≥j. Stationarity forces
state_t=state_(t-(j-i)) for every j<=t<L. Thus(mu=i,p=j-i) is an admissible
pair and m(w)≤j≤|S|. Both inequalities give equality. This proof does not
assume global periodicity from finite output agreement.

## General marker-exclusion theorem

For arbitrary deterministic stationary S and report alphabet O, let
start<=stop and b=q(U^stop(s_0)). Suppose q(U^t(s_0))!=b for every
start<=t<stop. Then source states at every position in[start,stop] are
pairwise distinct, forcing at least stop-start+1 states.

If state_i=state_j with start<=i<j<=stop, iterate both stop-j more steps.
The later state is state_stop; the earlier position i+stop-j lies inside the
gap and hence has report !=b, contradiction. **Interior reports can be
nonconstant.** VOYAGER's zero-gap/one-endpoint theorem is a special case.
This theorem was kernel-checked for arbitrary types, with no finite alphabet
or finite source hypothesis needed for the injectivity conclusion.

Periodic markers at gap p give the lower bound p; a p-cycle with one marker
attains it. Sparse/nested marker gaps give their exact finite-horizon lower
bounds. Unbounded marker gaps with infinitely many markers exclude a fixed
finite stationary source: any finite orbit eventually cycles, and a cycle
containing the marker has bounded return gaps. If infinitely many markers
are required, the eventual cycle cannot omit it. No inference of actual
infinite execution is made.
