## 3. Proposed SUCC objects

Fix finite nonempty output alphabet O, finite authorized action alphabet A,
and a total behavior f:A*→O. A realizer is a pointed stationary deterministic
Moore machine (S,s₀,(Uₐ),q) with f(w)=q(U_w(s₀)); actions execute left to
right. Define residual fᵤ(v)=f(uv), and u≡v exactly when fᵤ=fᵥ.
For one action, write x:ℕ→O and residual xᵢ(k)=x(i+k).
All counts concern reachable mathematical states. Extra unreachable or
behaviorally duplicate physical states are permitted and are not recovered.

## 4. Candidate theorem

**CLASSICAL, direct derivation:** f has a finite deterministic realizer iff
its residual set R={fᵤ:u∈A*} is finite. The minimum reachable state count
is |R|. For a one-action stream this is equivalent to ultimate periodicity;
the sharp count is μ+p, with μ the least periodic-tail starting index and
p its least positive period. Purely periodic streams have μ=0. A constant
stream has p=1, not zero. A supplied nonminimal decomposition need not give
the count.

For a finite prefix w of length h>0, the sharp count is

\[
 D(w)=\min\{\mu+p:0\le\mu<h,\ 1\le p\le h-\mu,
 \ \forall\mu\le i<h-p, w_i=w_{i+p}\}.
\]

For the empty prefix D(ε)=1, since a pointed machine is nonempty.

## 5. Proof attempt

Same reached source states imply identical residuals, so every realizer
has at least |R| states. Conversely take R itself: q(r)=r(ε),
Uₐ(r)(v)=r(av), and initial state f. If fᵤ=fᵥ, their a-derivatives agree,
so transition definition is well defined. Induction gives f after every
action word. This proves both directions and sharpness.

For one action, finite residuals force xᵢ=xⱼ for i<j, hence periodicity
from i with period j−i. Conversely μ+p suffixes suffice. They are distinct:
any equality involving a preperiod suffix produces an earlier periodic
tail; equality of two cycle phases contradicts primitive tail period.

For finite w, a compatible (μ,p) constructs μ+p states, advancing once
and looping from μ+p−1 to μ, with their first μ+p reports. Repeated use
of the displayed equality reproduces w. Any smaller realizer repeats an
orbit state before its state bound; its first-repeat lasso supplies a
compatible pair. If its size is at least h, the lower bound follows from
D(w)≤h. Thus this finite claim does not require an eternal measured trace.

## 8. Remaining obstruction

General finite multi-action samples do not specify total f. For prefix-closed
sample addresses P, a ≤N-state completion exists exactly when P admits a
partition into ≤N blocks that respects supplied outputs and gives one target
block for each defined block/action edge. Necessity uses reached states;
sufficiency fills missing reports/transitions arbitrarily. Minimization is
over these partitions, not truncated residual equality.

Source memory and observer memory answer different questions. An observer
that stores only the latest binary report needs two report states even while
receiving a nonperiodic pulse stream. A source generating that entire stream
under autonomous stationary deterministic dynamics has no finite realizer.
Predicting all authorized continuations requires residual memory; merely
receiving or checking a bounded history need not. External action schedules
can carry uncounted memory, so multi-action traces need not be periodic.
