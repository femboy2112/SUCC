## 3. Proposed SUCC objects
Actual source graph G_D has vertices Gaussian primes z in Z[i], and edges z->w iff 0<|z-w|^2<=D, with exact integer D>=1. Prime classification: off-axis norm prime; on-axis coordinate prime congruent 3 mod 4. Observation enumerates every allowed finite displacement around each discovered vertex. Coordinate voltage is w-z in Z^2. Quotient reduction q_m(z)=z mod m records winding; arbitrary voltage labels are excluded from source-derived transport. Code D<=25 and finite vertex budget; exhaustion raises.

## 4. Candidate theorem
If a finite set K of actual Gaussian primes is nonempty, connected in G_D, and contains every prime neighbor of each member, then K is an entire connected component of the INFINITE G_D. This yields a rigorous finite moat certificate for that starting component.
For coordinate-derived voltage, every actual closed graph path has zero total displacement. A quotient-closed path may have nonzero displacement in mZ^2; this is winding of its lift, not nonzero curvature on the original coordinate graph.

## 5. Proof attempt — complete
Every finite path starting at K stays in K by induction: its initial vertex belongs to K; local neighbor closure keeps the next vertex in K. Thus the component of any member is contained in K; connectivity gives the reverse containment. Only finitely many neighbors exist per vertex because the step alphabet is bounded, so closure can be exhausted without searching an infinite exterior. Breadth/depth exploration constructs a connected K by adding only actual neighboring primes. Returning successfully means every member was explored; if the budget is hit no closure result is returned.
For a path z_0,...,z_l, sum_j(z_(j+1)-z_j)=z_l-z_0. This vanishes if z_l=z_0. If q_m(z_l)=q_m(z_0), only divisibility of both coordinates by m follows. Hence quotient holonomy is a different report type.

## 8. Remaining obstruction
Finite components for three D values do not bound all components or all step sizes. A uniform all-D theorem needs an arithmetic construction and its correctness proof. Source-derived quotient cocycles must retain every true step and source-prime exception; an arbitrary voltage group's holonomy cannot be substituted for this graph.
