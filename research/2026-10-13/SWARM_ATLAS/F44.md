# SWM-F44 — Identifiability cannot be bred out of an invisible fiber

## 1. Original question

When are arbitrary computation and model proliferation unable to identify a source target, and what minimum instrument defect certifies that failure?

## 2. Existing mathematical context

[Wolpert–Macready's original publication](https://research.ibm.com/publications/no-free-lunch-theorems-for-optimization) concerns averaged optimization under specific problem ensembles. The theorem below is instead exact observational identifiability; it does not import an unrestricted no-free-lunch slogan. VOYAGER's trace quotient and Angluin's [query model](https://homepages.math.uic.edu/~lreyzin/papers/angluin87.pdf) supply the appropriate classical context.

## 3. Proposed SUCC objects

Complete finite deterministic source X, authorized actions U_a, readouts r_i, all-word trace Φ, behavioral E=kerΦ, target T:X→Y. Experiments are mathematical words; reset rights are not implied. Model-generated outputs may use only genuine available reports and deterministic computation. Randomized learners use a declared source-independent seed.

## 4. Candidate theorem

T factors through Φ iff T is constant on E-classes. If xEy but T(x)≠T(y), every deterministic adaptive policy using only authorized actions/readouts has identical observed decisions on x,y whenever it operates lawfully, so cannot be correct on both. A randomized policy has identical terminal answer laws on the pair and cannot guarantee correct distinct values with probability one. Adding source-blind syntax, computation, parallel models or received copies of the same reports does not alter E.

## 5. Proof attempt

Factorization necessity follows from equal Φ values. Sufficiency defines g(Φ(x))=T(x), well-defined by constancy. For an adaptive policy couple identical seeds. Initially observations agree; given the same previous transcript the policy selects the same action/readout, and all-word equivalence guarantees equal ensuing reports. Induction gives identical finite transcripts and terminal values. For non-total instruments include availability in the observational contract (F48); otherwise availability itself can leak a distinction.

This is a necessary/sufficient criterion for all mathematical word queries, not a sufficient criterion for jointly performing those queries on one destructive carrier. A finite complete X admits a finite separating probe basis, but physical preparation/survival is a separate premise.

## 6. Crucible

Four-state source with action (0↔1,2↔3) and readout (0,1,0,1) has E-classes {0,2},{1,3}; hidden-copy target (0,0,1,1) differs on witness (0,2). Every word is simply parity of length, so the witness is decisive for arbitrary depth. In the Heisenberg family all x values in a fixed (y,z)-fiber are similarly invisible. Add W(x,y,z)=(z,y,x): r∘W=x, so the new toolkit expands to all p³ states. This is a genuine new instrument, not increased confidence in the old one.

The independently executed dihedral and zero-coupling controls demonstrate that more models cannot recover missing source information by guessing the favored group family. F48 adds a stricter negative control: individually source-identifying branches may fail joint single-carrier execution.

## 7. Verdict

**CLASSICAL / PROVED LOCAL** exact target-factorization and adaptive no-go. A minimal certificate consists of two observationally equivalent alternatives with different target values. Computation is not declared useless generally; this specific contracted information language is insufficient.

## 8. Remaining obstruction

If E itself is not completely known, failure to find a separator is not a certificate. Under unknown cardinality/partial transition tables, delayed-separation source extensions can match all tested words. Next discriminating input: an available new readout/action, a proved source-family restriction excluding a rival, or a separately sound mathematical target theorem.
