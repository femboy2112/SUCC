\[
\sigma_i(u)=T_u(P_i),\quad A_u=\{i:\operatorname{tr}\sigma_i(u)>0\},\quad
U_i(u)=\operatorname{supp}\sigma_i(u).

Admitted finite/infinite words have \(A_u\ne\varnothing\) at every prefix. Prefix extension is information order; directed joins are consistent unions. ## 5. Proof attempt

**Support and reports.** For \(\Phi(X)=\sum_aK_aXK_a^*\), positivity gives
\(\operatorname{supp}\Phi(X)=\operatorname{span}_a K_a\operatorname{supp}X\): the kernel consists exactly of vectors annihilated by every \(X^{1/2}K_a^*\). These support maps preserve inclusion, identity and composition. Dominance therefore persists; a nonempty continuation cannot kill i while preserving j. Conversely, if \(U_j\not\subseteq U_i\), a rational vector \(v\in\ker\sigma_i\) with \(v^*\sigma_jv>0\) exists by rational linear algebra. The rational projector \(P_v=vv^*/(v^*v)\) kills i and preserves j. Its complementary projector makes a complete rational instrument; identities continue its surviving branch. This proves the toolkit-relative iff, without a normalization square root.

The original target \(g(P_i)=i\) factors through a history precisely when it is constant on \(A_u\), hence precisely at a singleton. Exclusions never reverse and every zero likelihood has a finite witnessing prefix. Consequently the singleton-bit report is Scott-continuous. First-safe-choice retains its reported bit because dominance persists, even if another bit later also becomes safe.

**Two distinct no-go proofs.** On the all-identity oracle word, any continuous selector's output b is fixed by finitely many input coordinates. Place \(P_{1-b}\) beyond all these coordinates and use identities elsewhere. This admitted word has unique survivor \(1-b\), contradicting the same output b.

Separately, for a program index e, bounded simulation of \(\varphi_e(e)\) supplies identity branches until a 0/1 output b appears, then repeated \(P_b\). Every instance satisfies the promise. A total computable source selector would give total computable g with \(g(e)=\varphi_e(e)\) whenever that output is a bit. A program for \(x\mapsto1-g(x)\) has some index k, giving \(g(k)=1-g(k)\), contradiction. No oracle-name/program-index equivalence is assumed. A total stabilization-index selector also decides ordinary halting: use identities until halt, then \(P_0\); inspect bounded simulation at its returned index.

For the oracle comparison, compute exact rational prefix likelihoods and enumerate i when one becomes zero; this is negative information for nonempty \(A_\infty\). Conversely, an exclusion name emits identity for padding and \(P_{1-i}\) when i is excluded. A nonempty promised set never excludes both bits. Its survivor set is exactly that closed set; output conversion is identity in both directions. These are oracle-relative computable name transformations, not finite programs for arbitrary streams. Exact zero decidability is load-bearing; merely computable real coefficients do not provide it.

**Certified periodic repair.** For the cycle CP map F with Kraus operators \(L_a\), define
\[
W_k=\ker(F^{*k}(I)),\qquad W_0=0,
\qquad W_{k+1}=\bigcap_a L_a^{-1}W_k.
\]
Zero absorption makes this an increasing subspace chain. Its fixed recurrence makes any equality \(W_k=W_{k+1}\) permanent; otherwise each step increases dimension. Thus \(W_2\) is final on a qubit. For the preperiod state \(\sigma_i=T_\mu(P_i)\),
\(\operatorname{tr}F^k\sigma_i=0\iff\operatorname{supp}\sigma_i\subseteq W_k\).
Survival after two cycles therefore means survival at all cycle boundaries. Death inside a cycle would imply death at its next boundary, so no intermediate prefix is missed. This proves the displayed deadline. More generally a faithful positive cone of known face height H has the recurrence \(Z_{k+1}=K\cap F^{-1}Z_k\) and deadline \(\mu+H\lambda\), with exact membership supplied separately. Stationarity of the **selected cycle map**, not height alone, certifies the plateau.

## 8. Remaining obstruction

An omega+1 token meaning “this infinite record is now completed,” issued only at the infinite word, is not Scott-continuous: finite identity prefixes all yield \(\bot\), while their union yields the token. B13's ordinary finite-tree union proofs have finite birth support; a limit-only sealing rule changes that calculus. This does **not** ban finite reports of universal existence already proved from the supplied promise, nor finite proofs about a fully specified generator. It separates such mathematical certification from observing or running infinitely many events. Likelihood can tend to zero despite every finite prefix surviving.

The next falsifier is a purported selector whose actual input omits a scheduler bound, whose future toolkit omits the separating filter, or whose current interface omits retained source-correlated memory. κ is exact model contact; φ is explicitly toolkit-relative; σ is declared original/source/scheduler lineage; ρ includes proposal ownership and downstream interpretation. None certifies hardware provenance, cognition, quantum speedup, RH or completed Weil positivity.
