# Candidate: fixed-history source choice can remain uncomputable

STATUS: CLASSICAL / PROVED LOCAL, PAPER. Fix the original source class C={P0,P1} on a qubit. Given a program index e, simulate phi_e(e) for n steps. Its common source-independent rational CP branch is identity until a0/1 output is detected, then project onto P0 (output0) or P1 (output1), and retain that projection thereafter; other outputs may leave identities. Every finite prefix supports some source in C, and one pure source supports every prefix. Complete each projector by its complement if a full instrument is wanted. This is a computable externally scheduled word, not a finite autonomous apparatus.

If a total algorithm selected a member of C compatible with every prefix from each such program description, compose it with e→word(e) to obtain a total computable bit g(e). Whenever phi_e(e)=0 it must output0; whenever phi_e(e)=1 it must output1. A program computing1-g has some indexk, so phi_k(k)=1-g(k), contradicting the required selection at k. Thus there is no total uniform selector despite the existence of a common source for every instance. No physical halting computation or infinite record was executed.

A separate stabilization-index selector would decide ordinary halting using identity until halt, then a projection: if its certified index had rank2 the machine never halts, while rank1 certifies a halt. Dimension bounds the number of rank drops, not the last index.

Candidate exact comparison object: closed choice on{0,1} with negative information (enumeration of excluded points). An exclusion can be encoded by a rational projector killing that initial pure source; the nonempty-set promise preserves a survivor. Conversely, exact rational prefix computations enumerate the pure candidates with zero likelihood, so closed choice returns a survivor. For merely computable real coefficients, decidability of exact zero fails; that converse is deliberately restricted to exact rational branch tables.

Primary classical context: Brattka–Gherardi–Hoelzl, Probabilistic Computability and Choice, https://arxiv.org/abs/1312.7305. Definition2.5 and the two-point C2/LLPO discussion on pp10–11 were inspected directly. Distinguish representations: the diagonal no-selector theorem above takes finite program indices; the proposed Weihrauch comparison instead takes an arbitrary infinite rational-branch word as a Baire-space name (oracle), with the nonempty-prefix promise. Negative information streams may be noncomputable; their branch words are computable relative to that stream, not necessarily ordinary finite program descriptions. No equivalence between those input representations is asserted. Mixture I/2 is an easy common witness for every nonzero positive effect but lies outside C; silently enlarging C changes the question. Zero-error identification of an actual prepared state via a genuinely new initial measurement is a different task.
