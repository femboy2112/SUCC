# Exact-instance formal applications and retained source obligations

Round II adds a narrow executable bridge, not a general proof importer. The
existing capsule auditor remains an integrity/dependency checker. Its transitive
unresolved-premise and OPEN/proved-label regressions remain mandatory. Neither a
fresh hash nor a recorded declaration name discharges a mathematical assumption.

## Eight distinct statements

| Stage | Object checked | Authority and limitation |
|---|---|---|
| 1 | Exact runtime source files, source identity, epoch | Fixed byte pins and explicit model binding; identity is declared, not physical authentication |
| 2 | Mathematical input and output model | Natural shift/prime-scale word or complete rational cyclic operator tables; no arbitrary prose theorem |
| 3 | Imported theorem parameters and premises | Nat versus Rat; chronological order; nonempty fibers; counting versus Haar conventions; all retained |
| 4 | Generated Lean term and statement | Deterministic fixed grammar; generation itself has no proof authority |
| 5 | Fresh kernel execution of that statement | Exact generated declarations, full elaborated types, axiom report, exit status, compiler and dependency pins |
| 6 | Source-to-model identification | Complete finite parameter/table replay plus reviewed translation; universal Python correctness and external source identification remain obligations |
| 7 | Runtime receipt | The particular execution and exact output, with a separate finite scope |
| 8 | Global application | Allowed only with its actual hypotheses; neither a finite table nor a conditional Lean theorem proves the original infinite Suzuki sign |

`formal_instance_bridge.py` admits only two grammars. `replay_packet` reconstructs
the entire packet from the pinned mathematical API and compares canonical bytes.
It rejects a changed composition order, fiber factor, coefficient type, source
epoch, missing obligation, or unsupported universal Python status, even after an
attacker recomputes a matching hash. The packet includes no executable commands.
Source identifiers are never interpolated into Lean syntax.

For the affine grammar, the Python word is in chronological order. `S,t` maps to
`Step.shift t`; `V,p` maps to `Step.scale p`. The compiler checks the actual
`Word.PrimeWord` predicate separately from the semiring normalization. A successful
generated `all_inputs` theorem quantifies over every natural input of **that fixed
serialized word**. It does not quantify over all possible Python executions.
The target source is the additive natural coordinate used by
`finite_affine_presentation`, not the distinct unit-origin profinite chart.

For the retract grammar, `fine=k*n`, and `(r,t)` maps to `r+n*t` in
`Fin(k*n)`. Tables enumerate every rational coordinate-basis column of pullback,
average and projection. The Lean goals compare them to the actual cyclic
definitions, at every finite row and column. `cyclic_average_pull` is instantiated
with a proved positive fiber count and still quantifies over arbitrary rational
functions at that fixed finite modulus. Counting adjoint is the raw fiber sum;
the normalized average divides by k. No complex Fourier statement is imported.

## Replay and trust

The script `scripts/formal_instance_bridge_probe.py` has a generation-only mode
whose output explicitly says kernel verification was not run. Its optional kernel
mode requires the pinned YEAN checkout and the fresh Round-II dependency manifest.
It checks the compiler binary/version, pinned Lean text, all recorded dependency
sources and compiled sidecars. It then freshly compiles the local import closure
into its own build directory before compiling generated instances with trust level
zero. Thus a local cached object cannot silently replace the pinned local text.
External Mathlib/Lean package caches are reused with their recorded hashes and Git
pins; a complete external source rebuild is not claimed.

The full `#check` output with `pp.all` and every `#print axioms` result are retained.
Only `propext`, `Quot.sound`, `Classical.choice` are in budget. A failed compiler
exit, missing declaration or out-of-budget axiom fails the replay. The source and
dependency bytes are checked again afterward. Hosted CI status is a separate
field and is never inferred from this local command.

This remains an auditable translation-validation experiment. The generator,
Python interpreter, filesystem, compiler binary and dependency supply chain are
part of its execution trust boundary. A hostile process can lie about bytes or
substitute a whole execution environment; SHA256 is not a semantic oracle. The
repository does not supply verified extraction or a universal correctness proof
for the Python normalizer. These obligations appear in every accepted packet and
are not marked discharged by kernel success.

The inherited nine-capsule bundle remains unchanged. Round-II claims use a separate
bundle and preserve the original four-low sign as `UNVERIFIED / OPEN_TARGET`.
Conditional observer and Schur theorems retain source identity, positivity/range,
continuity and all-stage premises in their exact domains. No automatic promotion
from an exact finite model to the analytic source is provided.

## Executed instances and retained failures

The [final local replay](observer_schur_receipts/bridge-kernel-final/replay.json)
checked seven generated declarations after freshly compiling five local imports.
The fixed chronological word S1,V2,S3,V3 has normalization 6x+15 and proved prime
admission. The 4-to-2 quotient instance checks every pullback, average and projector
basis entry against the actual Lean definitions, plus retraction for all rational
functions on Fin2. Types and per-declaration axioms are in the kernel transcripts.
The normalized/all-input affine theorems use `propext`; the other five use the
declared three-axiom budget. Deliberate wrong-offset and missing-normalization
Lean instances were rejected by normal kernel diagnostics.

The first attempt left primality goals unsolved; the second left finite index and
cardinality goals unsolved. Their nonzero exits and out-of-budget `sorryAx` reports
were rejected and retained in bridge-kernel-01/02. Explicit kernel reduction of
the remaining concrete decidable propositions repaired the proof generator.
The third replay passed; the final replay adds the two deliberate mutants and
records implementation hashes before and after. None of the failed output is
counted as proof authority. The successful code contains no admitted proof.
