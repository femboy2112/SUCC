# Frozen finite conditional-cofiber holdouts — pre-result selection

**Written before computing ANY selected finite Fourier coefficients at the following horizons/modes in this research round.**

- Authentic zero-seeded four-pole BBP rational recurrence only; no \(\pi\) decimal digits.
- NEW horizons: \(N=768,1536,3072\) (previous explorations used 256/512/1024/2048).
- NEW harmonics: \(h=9,11,17\) (previous exploration used 1,3,5,7).
- Finite local carrier time class lengths: \(Q=16,256\), both dividing every N. Since the real BBP states are the original rational source and F(n) is a 2-adic isometry, time modulo Q is a permutation-relabeling of source carrier \(a_{n,r}\).
- Conditional cross-cofiber energy
  \[G_{N,Q}(h)=\frac{Q}{N^2}\sum_{a=0}^{Q-1}\left|\sum_{0\le n<N; n\equiv a\pmod Q}e^{2\pi ihU_n}\right|^2.\]
- **Strict target before evaluation:** for every one of the 18 combinations, \(G_{N,Q}(h)<2Q/N\). This is a FINITE numerical arithmetic prediction only, NOT an all-N theorem or proof of normality. Record failures individually.
- Exact proof oracle: Fraction source and reduced real phases, rational Machin bounds for pi, dyadic phase grid, rational sine/cos Taylor enclosures, explicit outward errors. No floating-point verdicts. A separate direct raw-pole float oracle may be used ONLY for numerical cross-checks.
- Adversaries: same four-pole forcing with real seed \(-\pi/16\) (asymptotically coherent and \(G\to1\)); same original four poles with normality-unknown authentic zero seed; same-source Thue–Morse completion \(c_{TM}-\pi/16\) (proven nonnormal with irrationality exponent 2), which can still pass many anti-lock probes. These must remain DISTINCT.
- Global proof requirement unchanged: an all-horizon original-source bound with \(G_{N,Q(N)}(h)=o(1)\) for each fixed h and some source-justified \(Q(N)=o(N)\), or a weaker genuine signed implication. The upper \(2Q/N\) is an unproved and potentially too strong conjectural finite pattern, not a generic consequence of normality.

Same researcher/reasoner preregisters and runs the experiments; this is not independent blind evaluation.
