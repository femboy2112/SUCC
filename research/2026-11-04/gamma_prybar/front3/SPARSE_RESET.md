# A sparse forcing mutation with exact prime checkpoints and authentic selected-state denominators

**Status.** Paper countermodel, conditional only on the source arithmetic theorem of PR #497, PF-05 (equation PF-5 at 4383bd31340af700e312f13d7ef28af090c152d5), namely log den(U_s)=(6+o(1))s for the authentic zero-seeded four-pole recurrence, and classical PNT. No assumption about the digits of π. This is a single deterministic alternative sequence for each chosen finite audit horizon H. Its exceptions occur at infinitely many composite-clock indices. They disqualify it as the authentic source. This directly tests which restrictions of that source rule can force cancellation.

**Theorem.** Given any fixed H there exist rational f_n and V_0=0, V_n=16 V_{n−1}+f_n, with the following simultaneous properties.

* f_n=r(n) for n≤H, at every designated prime birth (8n−7 prime >5), and outside a set containing O(log N) indices ≤N. Every f_n is positive and strictly decreasing in n. The difference from the authentic forcing is O(exp(−c n)) for some absolute c>0, hence invisible to every fixed Laurent jet. At every designated birth the complete exact injection, including its denominator and Gamma pin, agrees literally.
* den(V_n)=den(U_n) in lowest terms at every n. For every prefix N the full intrinsic LCM of all f_n through N equals the original forcing LCM Q_N, including prime powers at 2,3,5. Both sequences carry full unwrapped integer lifts. Equality of their carries is not asserted.
* Let b be the first appearance of any prime p in an authentic forcing denominator. Then whenever b≤n≤b+floor(b/64) both the p-primary state and forcing agree with the originals (equal classes in Q/Z_(p)). All such windows hold simultaneously. This includes inherited impressions after nearby births as well as the actual injections.
* For a fixed dyadic rational C and the authentic tail T_n=∑_{j>n}16^{n−j}r(j), V_n=16^n C−T_n+O(exp(−c n)). In particular the completed mutant boundary is C, every fixed normalized Weyl average tends to one, and J_{A,q_A}(V)=(1−o(1))q_A. These conclusions hold with all constants allowed to depend on the initial prefix unless called absolute.

**Construction and proof.** Write d_s=den(U_s), u_s=d_s U_s, so gcd(u_s,d_s)=1. Each original forcing denominator divides lcm(8n−7,8n−4,8n−3,8n−2); hence Q_s divides lcm(1,...,8s), and d_s divides Q_s. In particular all prime powers appearing as factors of d_s are ≤8s. Choose a large integer s_0>H, s_0≡2 mod 3. Put s'=s+3 floor(s/96) at each reset. For sufficiently large s, s/64≤s'−s≤s/32, so these indices up to N are O(log N). As 3 divides 8s−7 and 8s−7>3, no such index is a designated prime birth.

Put α_j=∑_{i≤j}16^{−i}r(i), α=π/16 and C=16^{−2s_0} floor(16^{2s_0}α_{2s_0}). The authentic source Green bound implies |C−α|<2·16^{−2s_0}; this is an exact rational construction using an explicitly declared finite future prefix. Let V_n=U_n before s_0. At a reset s, protect all primes dividing any positive integer in (m−l,m], where m=ceil(17s/2) and l=s+3. This interval contains every original raw denominator at each j∈[s−floor(s/32),s'], since those denominators are between 8s−s/4−7 and 8s+s/4. Let M be the product of the full p^{v_p(d_s)} over protected primes dividing d_s, and R=d_s/M. These two integers are coprime.

We bound the occupied modulus. For p≤l the contribution from the first powers in M is ≤θ(l)=s+o(s). Higher powers contribute at most O(sqrt(s) log s), since they require p≤sqrt(8s) and p^{v_p(d_s)}≤8s. For p>l all exponents are one for large s, and any such p dividing a member of (m−l,m] divides the integer binomial(m,l): the numerator contains p while l! has none. Therefore

    log M ≤ θ(l)+O(sqrt(s) log s)+log binomial(m,l)
          ≤ (2+log 9+o(1))s.

Here the last bound follows from binomial(m,l)≤(em/l)^l. The retained cofactor thus has log R ≥ (4−log 9+o(1))s, exceeding 1.8s asymptotically. This is an upper bound on the cost of paying all protected primes, independent of any assumption about small prime gaps.

For any real target t an integer a≡u_s mod M coprime to d_s exists with |a−d_s t| ≤ M(4^{ω(R)}+3), where ω counts distinct prime factors. Write a=u_s+Mk. In a block of L consecutive k, inclusion–exclusion counts those coprime to R after the affine substitution with error at most 2^{ω(R)} from L φ(R)/R: for each squarefree divisor there is one prohibited divisibility class as M is invertible. Since φ(R)/R≥2^{-ω(R)}, taking L=4^{ω(R)}+1 ensures a survivor. Coprimality at M was paid by the congruence to u_s. Choose the first survivor to the right of the target for a deterministic rule. As every prime of d_s is ≤8s, PNT yields ω(R)≤π(8s)=O(s/log s). Using log d_s=(6+o(1))s from #497,

    |a/d_s−t| ≤ exp(−(4−log 9+o(1))s) ≤ exp(−s)

for all sufficiently large s. Only the existence and sufficient onset are asserted, with no finite threshold extracted from PNT. The inclusion–exclusion bound gives an explicit exhaustive search, potentially expensive.

At the reset take the rational target t=16^s C−∑_{j=s+1}^{2s}16^{s−j}r(j) and set V_s=a/d_s. At every nonreset until s' take the original exact forcing. Define f_s=V_s−16V_{s−1}. The approximation to T_s in the target costs 16^{-s}T_{2s}, so |V_s−(16^s C−T_s)|≤2e^{-s}. In a nonreset block the difference is multiplied by sixteen per step. For s≤n<s' this gives

    |V_n−(16^n C−T_n)| ≤ 2 exp(−s+(log 16)s/32) ≤ 2 exp(−n/2).

Before the first reset the error versus this same target is exactly 16^n(α−C), bounded by 2·16^{-s_0} for n<s_0. Consequently |f_n−r(n)|=O(e^{-n/2}) at and after the first reset, and zero before. Taking s_0 large ensures the error at each endpoint is smaller than the genuine r(n) and one quarter the smaller adjacent genuine decrement. This is possible because r(n)∼15/(64n²) and r(n)−r(n+1)∼30/(64n³) from its explicit rational expression. Thus f_n stays strictly positive and decreasing across every splice. Since 16^n C is integral at n≥2s_0, all phases have distance O(n^-2) to zero. All fixed characters tend to one and all ordered pairs in [A,2A) have distance O(A^-2), proving the energy assertion. The expression for V_n also gives lim 16^{-n}V_n=C, the mutant's completed boundary.

It remains to check the *timewise* conductor and passports. At reset s, the numerator is a unit modulo d_s by construction, so its reduced denominator is exactly d_s. For a protected p the difference V_s−U_s lies in Z_(p): when p|d_s its full power was protected, and otherwise both states are integral there. Until the next reset their difference is 16^{n−s}(V_s−U_s), still p-integral. Their reduced denominator exponents at p therefore agree. For an unprotected p, every original forcing between s+1 and s' has denominator prime to p. If p is odd, multiplication by 16 preserves negative p-adic valuation and adding p-integral terms leaves it unchanged. If both states started p-integral they remain so. At p=2 the authentic denominator is always odd, the mutant starts p-integral, and integrality is preserved. This proves denominator equality at every n. Over any finite prefix, the forcing LCM equals the state LCM for either recurrence: V_n is an integral linear combination of preceding f_j, and conversely f_n=V_n−16V_{n−1}. The asserted entire intrinsic LCM equality follows.

To verify the post-birth window, the difference of states is p-integral before b by equal denominators. In any block with b≤n≤b+b/64, consider its reset s≤n. If s≥b then s−b≤b/64≤s/32, and b∈[s−floor(s/32),s']. If s<b then b≤n<s'. In both cases p is protected at s, since it divides an actual denominator at b and hence a raw denominator in the protected range. Prior to the first reset the states agree exactly. Therefore throughout the asserted window V_n−U_n is p-integral, as was the difference at b−1. Subtracting the two chronological recurrences proves f_n−r(n) is p-integral throughout. This proves the passport assertion with no uniform prime-gap assumption.

**Boundary and next discriminator.** The countermodel can answer exact finite future-source queries when picking its reset values. It changes the full accumulated integer numerator at those resets. It neither matches every forcing injection nor the literal carries, and it only guarantees the stated age range of each p-primary history. Its rational f_s may have many old denominator primes absent from the genuine single r(s); their *prefix LCM* still agrees exactly. The countermodel therefore challenges any proposed inference from the listed invariants alone, even when the authenticated source is sampled on density one. A surviving proof must detect the allowed sparse defects, through the exact local grid at the reset indices, a longer range cofactor constraint, or another test on the full numerator. No impossibility assertion about enforcing the original four-pole recurrence at **every** n. This countermodel and V1 concern different obstructions; neither proves a selected Weyl or energy saving.

**Independent variant avoiding the full PF-05 theorem.** One may use the smaller interval m=8s+ceil(s/4), l=ceil(s/2)+10 instead. It still covers every raw denominator specified in the proof. Since m/l≤17 for large s, the protected modulus has log M≤(1+(log 17)/2+o(1))s, strictly less than 2.42s. For a direct lower bound on d_s, take every prime 2s<p≤8s−7 with p≡1 mod 4. The raw residues of denominators modulo eight are 1,4,5,6. For p≡1 or 5 mod eight, p itself occurs and 2p and 3p do not have admitted residues. Higher multiples exceed 8s. Thus exactly one signed term up to s contains p, of weight 4 or −1. Its contribution retains p-adic valuation −1 under multiplication by powers of sixteen and addition of all the other p-integral terms. The product of these primes divides d_s. Fixed-progression PNT gives log d_s≥(3+o(1))s. The same unit-in-progression argument now bounds the rounding error by e^{-s/2} for all sufficiently large s, since 3−1−(log 17)/2>1/2. Expansion over s/32 steps still leaves O(e^{-n/3}) shadowing. All four theorem conclusions therefore have a proof using the original partial fractions, homogeneous tail completion and classical PNT-AP alone. The finite receipt uses the wider protected interval in the main derivation. Neither route requires using any draft code on the integration branch.

**Causal variant, including startup.** The finite lookahead can be removed in both proof variants. Write B for backward shift, ∇=1−B, and L=floor(s/2). The exact Green identity (16B−1)T_s=r(s) follows directly by shifting the source tail one time. Finite telescoping of 16B−1=15−16∇ gives the rational predictor

    H_s=(1/15)∑_{k=0}^{L−1}(16/15)^k ∇^k r(s),
    T_s−H_s=(16/15)^L ∇^L T_s.

The predictor uses only genuine injections whose indices are at most s. By integrating the four original fractions, r(s)=∫_0^1 t^{8s−8}P(t)dt with 0≤P(t)=4−2t³−t⁴−t⁵≤4. Thus T_s=∫ t^{8s−8}P(t)t⁸/(16−t⁸)dt. Applying the finite difference under the integral gives

    |∇^L T_s| ≤ (4/15) sup_{0≤u≤1} u^{s−L}(1−u)^L ≤ (4/15)4^{-L},

since s−L≥L. In particular |T_s−H_s|≤(4/15)(4/15)^L=O(exp(−0.65s)). At s_0 choose C by rounding 16^{-s_0}(U_{s_0}+H_{s_0}) down to mesh 16^{-2s_0}. Then 16^{s_0}|C−α|≤16^{-s_0}+|H_{s_0}−T_{s_0}|=O(exp(−0.65s_0)). At each reset use t=16^s C−H_s. All modular protections use only the current clock index and the authentic state at s, which can be computed recursively from the same input stream. With the narrower interval and elementary denominator lower bound the two errors together are O(e^{-s/2}) and still yield O(e^{-n/3}) shadowing throughout each block. The first step still meets the strict positivity/decrease check for large s_0. This proves the theorem even if the mutant may read only the authentic *current and earlier* inputs. The device retains the authentic reference state alongside its modified state. It does not assume a future prime list or π digits.
