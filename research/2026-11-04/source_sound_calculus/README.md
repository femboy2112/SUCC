# The SUCC source-sound calculus, with intrinsic LCM joins

**Research-only implementation — stacked on the November 4 observer-axioms draft.** This is a first executable, restricted judgement calculus, NOT replacement ZFC, a trusted proof assistant, physical quantum entanglement, or π/RH proof.

- **`PROOFS.md`** is the paper derivation and authority boundary. Read the `C_gcd → C_m ⊕ C_n → C_lcm` exact sequence and the original BBP source-subgroup theorem.
- **`source_sound.py`** is a closed finite proof-tree interpreter with source labels, verified model traces/journals, model-specific induction, conditional logical reasoning, and certified finite BBP/LCM operations.
- **`lcm_carrier.py`** is a no-float standalone independent oracle for original odd-LCM conductor growth, unwrapped integer phases and literal carries, and exact cyclic gluing/CRT phases.
- **`receipt_probe.py` / `FINITE_RECEIPT.json`** freeze one exact original-source prefix and cyclic-join data as a deterministic SHA256 receipt, with pi/RH status OPEN.
- **`CLAIM_LEDGER.md`, `SOURCE_MAP.md`, `VALIDATION.md`, `NEXT.md`** record scope, dependencies, actual tests and next proof obligations.
- Root tests: `tests/test_source_sound_calculus.py`, `tests/test_source_sound_receipt.py`, and **hosted native checkout** `tests/test_source_sound_repo_bridge.py`.

The standalone tests evaluate mathematical formulas and synthetic observer sources. The native bridge separately verifies exact agreement with SUCC's immutable production integer BBP engines once the branch is checked out. Never assume this research project has certified real-world physical instruments.
