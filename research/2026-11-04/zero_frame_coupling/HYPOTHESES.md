## Finite design, fixed before execution

Development: A=128,h=1 at the actual critical schedule; this repeats parent
calibration. Fresh cases: A=256,h=7 and A=512,h=-3 at that same schedule.
Diagnostic cases: A=128,H=128 A^2 (reciprocal tuning) and A=256,H=7
(fixed character). Diagnostic frequencies are never called selected depths.

For each case run all 16 cells of independently toggleable factors:
angular orientation +Y/-Y; angular seed 0/1/5; radial lag 0/1;
uniform/reciprocal weight 8/(3(n/A)^3). Preserve full signed complex means,
maximal consecutive sums and the complete factorial mixed differences.
An orientation reversal changes the angular source; a seed change changes
the boundary; lag and weight change the observer. A measured cross-term is
nonadditivity only. It does not identify a mechanism or prove an asymptotic.

Controls: source-only radial Z, artificial exact anti-companion, same-four-pole
coherent real seed represented through a rational Green-tail enclosure,
integer-lift mutation, and a nonperiodic rational Cayley chart. The normal
wrong seeds and ternary source mutant have analytic constructions in the
read-only #505; no finite proxy is substituted for those infinite objects.

Every phase is reduced as an exact rational before trigonometric evaluation.
Direct unwrapped Fraction recurrences must match an independent common-LCM
integer recurrence for U,Y,Z. Character and maximal-sum errors are enclosed
using rational arithmetic. Save raw integer-grid observations, state/carry
hashes, source pins and explicit error budgets. No amplitude trend is a proof.

Pass for the main mission requires an all-horizon source-selected inequality
for every fixed nonzero h, with sharp-subinterval control, or a valid direct
fixed-h Weyl theorem. Exact identities are category B; conditional estimates
C; scoped impossibilities D; unproved proposed savings E. A genuine new
unconditional source-coupled inequality is category A.
