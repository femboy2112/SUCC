# Countermodels and no-go: coherence at infinity needs compatibility and access

**1. Pure GHZ_N incompatible across sizes.** For \(|G_N(\theta)\rangle=(|0^N\rangle-e^{i\theta}|1^N\rangle)/\sqrt2\), \(\operatorname{Tr}_{N+1}|G_{N+1}\rangle\langle G_{N+1}|\) has ZERO \(|0^N\rangle\langle1^N|\) coherence; \(|G_N\rangle\langle G_N|\) does not. Therefore no single state on the standard quasilocal algebra has every local restriction equal to these pure finite GHZ states.

**2. Infinite GHZ local phase disappears.** Every fixed finite proper margin of \(|G_N(\theta)\rangle\) is independent of θ, so the infinite-volume limit as a state on quasilocal observables is the same separable mixture for every θ. A hypothetical nonlocal all-site parity is a different type of observable; do not silently include it in the quasilocal C*-algebra.

**3. Cluster-state finite boundary requires a BUFFER.** Pure \(|C_m\rangle\) is not the finite restriction of the semi-infinite state to the first m sites. The correct compatible \(\rho_m^\infty\) equals the partial trace of \(|C_N\rangle\) once \(N\ge m+1\). Failure to pay the extra neighbor would incorrectly conflate pure and mixed local reductions.

**4. Local entanglement is not maximal extensive entropy.** A connected path graph has one ebit across ANY single contiguous cut, independent of chain length. It is genuinely entangled across each such cut but follows an area law, not volume-law unrestricted entanglement.

**5. All local marginals can miss correlations.** In the connected cluster every single-site reduced density is \(I/2\), even after arbitrary local source rotations; the B_m many-site operator carries the combined phase. Local marginal equality does not imply global state equality.

**6. The source group witness is not cost-free.** \(\|B_m\|=2^m\); its norm-one version has expectation \(2^{-m}e^{i\sum\theta}\). No norm-convergent \(B_\infty\) follows, nor does one get a measurable global phase merely because all finite correlators exist.

**7. Entanglement not needed to encode one scalar phase.** For a single separable equatorial qubit \((|0\rangle+e^{i\theta}|1\rangle)/\sqrt2\), \(\langle X+iY\rangle=e^{i\theta}\). Thus a coherent source phase witness alone cannot prove that the authentic arithmetic source is quantum-entangled or carries quantum speedup.

**8. Coherent original-forcing wrong seed is a fatal source-blind control.** For changed seed \(s_*=-\pi/16\), the same four original pole injections yield \(U_n(s_*)=-T_n\to0\). An identical pure infinite cluster encoding exists for every source time and h, and \(\omega_{n,h}^{(s_*)}(B_2)\to1\), not Weyl zero. The original U0=0 is necessary authentication but is not itself a signed mixing theorem.

**9. Many channels may be algebraically redundant.** Defining extra even-site angles whose sum is θ_original does not manufacture statistically independent source families. The source prime-Frobenius angular/radial channels are precisely related by common provenance. Never use multiple channels as independent random phases.

**10. Noncommuting observations do not make every proposition true.** A single qubit with marginal \(I/2\) gives no simultaneous sharp values for X and Z, despite a well-defined global state and compatible restrictions. Infinite states preserve mathematical consistency, not logical omnitruth.

**11. Source-time versus site index.** Site count N→∞ and BBP time n→∞ are different limits. Any interchange requires a declared compatible observable and a uniform bound. At each fixed n the global state exists; that does not establish any time-average \(\lim_A A^{-1}\sum e(HU_n)\).
