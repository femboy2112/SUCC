# Hostile-control protocol fixed before first oracle execution

Scope: exact finite identities and rejection controls; no fitted model and no
numerical evidence promoted to an asymptotic theorem. The parameters below were
selected after reading the named source dossiers but before running this oracle.
They are new execution cases relative to this implementation, not guaranteed
globally unused epochs in the large repository.

- Independent literal-four-fraction versus shared `SelectedOrbit`: four rational
  seeds and all states through 83, including unwrapped lifts.
- Closed-loop holdouts: n in {0,2,7,17,31,67}, d in {1,3,7,11}; all must equal the
  same source sum for all seeds. Changed coefficient 4 -> 5 must break the original
  one-step source equation.
- History-tail aliases at depths {2,5,7}; equal projected tails and unequal lifts
  must begin exactly at the declared depth.
- Coherent completed seed beta=0, epochs {17,31,67}, h in {1,2,3}: the proved
  rational upper bound on |W-1| must be <1/2. The irrational wrong seed is handled
  by Green-tail enclosures; it is not rounded to a rational seed.
- Periods {1,2,3,5}: exact completed-orbit periodicity and character h=16^p-1.
- C5: every binary memory assignment must fail, one three-color assignment must
  decode every source; same-transcript/same-physical/different-target must reject.
- Phase-blind homometry, gauge grids {7,11,17,31}, 2-adic shadow depths 1..9,
  exact CB-3 lattice calibration through depth 6, and eventual-zero extension
  controls must produce their predicted failures of overstrong implications.
- Lean certificates must compile without `sorry` or custom axioms; report
  `#print axioms` output rather than claiming all theorem terms are axiom-free.

Unexpected output is a falsifier or implementation defect requiring explicit
repair and recording, not a reason to alter the mathematical claim silently.
