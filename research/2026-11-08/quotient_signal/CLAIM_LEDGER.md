## Precise shortcuts rejected

1. **REFUTED:** vanishing discarded conditional covariance forces vanishing
   retained signal. Counterexample b=conjugate(a), with phase-resolving P:
   discarded residual0, retained signal1.
2. **REFUTED:** signed discarded residual decreases monotonically under
   refinement. QC2 gives residuals0,-1/2,0 for three nested partitions.
3. **REFUTED:** universal gamma coefficient or universal second-order error
   for all bounded complements under the fixed equal-cell normalization.
   QC3–4 give explicit pi²h²/3 and first-order alias coefficients. This does
   not refute the user's unspecified source-specific gamma conjecture.
4. **REFUTED:** the completion-referenced gamma phase alone implies Weyl
   cancellation for every same-forcing seed. For s=-pi/16, U_n=-T_n,
   gamma calibration is unchanged and W_A->1.
5. **UNVERIFIED:** transfer gamma into original-zero covariance. An absent
   bridge is recorded as open theorem debt, not an impossibility theorem.

## Implementation failures retained

The hostile continuum oracle initially exceeded Python's integer-to-string
limit when serializing large rational endpoints. The repair stores proven
outward rounded rational endpoints; it does not alter global interpreter
limits or the mathematical oracle. Its first standalone source-review run
also lacked the repository import path; an explicit local path fixed it.
These failed invocations are not counted as successful checks. The source
probe's summary originally came from a recorded shell calculation; it was
moved into the producer before final replay so every result is reproducible.
Final inspection also removed an import-time integer-string-limit change
from the gamma oracle. Source-prefix hashes now use hexadecimal integers.
Its tests and entire oracle were rerun; every mathematical field matches
the full replay, with only the declared hash encoding and code hash changed.

## Evidence independence

Three independently assigned agents used common repository context and the
same model family. Their different derivations and implementations are
cross-checks, not independent scholarly referees. Gamma exact arithmetic
uses rational integral bounds/Machin/log intervals; the hostile continuum
oracle has its own rational Taylor implementation; the source measurements
reuse the pinned80-bit engine; their separate100-digit check shares source
data and independently evaluates phases, direct complements and cell sums.
No seed ensemble is a bearing for the single zero-seed assertion.
