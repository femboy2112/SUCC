## RHY-03. One-level *future-conditioned* digit defects — PROVED FINITE

Given N hexadecimal digits and **cyclic** k-word counts, let `p_k(w)` be the law of all N cyclic starts, including wraparound. Let `p_0(empty)=1` and define for j≥0

```

```

Because cyclic word counts have exact incoming and outgoing marginals,

```
0 <= δ_0 <= δ_1 <= ... <= 2,
||p_k−uniform_k||_1 <= Σ_(j=0)^(k−1) δ_j <= k δ_(k−1).    (RHY4)
```

**Proof:** for each j, the conditional defect at depth j is the L1 distance between the `(first digit,future j)` joint law and the product of the uniform first digit with the actual future-j law. Forgetting the last future digit is a stochastic marginalization, so L1 cannot increase under that projection: δ_j≤δ_(j+1). Add and subtract the product law in p_(j+1)−uniform_(j+1); marginalize the first coordinate to obtain the recursive k-step bound.

For B=16^j, the *already proved* SUCC word-energy refinement (PR #559, FRH-04) gives the exact signed/positive identity

```
E_(j+1)(N)−E_j(N)
  = 16^(j+1) Σ_(a,w)(p_(j+1)(a,w)−p_j(w)/16)^2.
```

Cauchy–Schwarz yields the finite bridge

`δ_j(N)^2 <= E_(j+1)(N)−E_j(N).                         (RHY5)`

The L1 defect ignores some rare enormous L2 hotspots, so the converse bound is false without further assumptions. It is a more forgiving target than proving the full moving-depth energy small.
