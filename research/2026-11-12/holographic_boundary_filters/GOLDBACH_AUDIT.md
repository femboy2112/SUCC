## 1. Exact completeness and normalization

The cone argument is correct under the explicitly stated assumption that
the data admit at least one nonnegative full histogram. If y lies outside
the cone generated by positive grades, a separating λ has
λ·v_j≤0 for j≥1 and λ·y>0. If λ·v_0≤0 as well, its evaluation against
every nonnegative full histogram would be nonpositive, contradicting
feasibility and λ·y>0. Therefore λ·v_0>0, and normalization to q(0)=1
is legitimate.

If full feasibility were removed, this normalization would not follow.
The document retains the hypothesis, and the verifier clearly states that
it checks a conditional implication rather than authenticating feasibility
or the source.

The cone is finite and polyhedral, hence closed. There is no hidden
infinite moment duality assertion. The code does not contain a complete
certificate-search algorithm; it verifies proposed exact coefficients.
That distinction is stated correctly.

## 2. Arithmetic grade ceiling

Let a=n+d and b=n−d, so a,b≥2. Then

$$
2^{\Omega(a)+\Omega(b)}\le ab=n^2-d^2\le n^2.
$$

The exponent is integral. Therefore

$$
\Omega(a)+\Omega(b)-2\le \lfloor\log_2(n^2)\rfloor-2.
$$

The implementation computes this ceiling as
(n*n).bit_length()−3, which is exactly the same integer. There is no
floating logarithm. The minimum n=2 has ceiling zero and a single
zero-grade point, correctly giving the pair 2+2.

At powers of two, d=0 attains the bound, so subtracting another one from
this universal ceiling would be false.

The support-authentication warning is substantive. The forged L=3 data
(m_0,m_1,m_2)=(9,16,46) are themselves feasible in the false carrier:

$$
(c_0,c_1,c_2,c_3)=(3,1,0,5)
$$

has exactly these three moments. Hence adding a generic nonnegative
feasibility check would still accept the forged packet and its bound three.
The real n=10 carrier has grade four and Goldbach count two. The needed
repair is authenticating the arithmetic support, not merely verifying
abstract moment consistency.

## 3. The midpoint-ten certificate is sharp in its relaxation

The independently computed grade sequence, in d=0,...,8 order, is

$$
(2,1,4,0,2,1,4,0,2).
$$

It gives the submitted histogram (2,2,3,0,2) and moments (9,16,46).
The polynomial q_4(j)=(j−1)(j−4)/4 is one at zero, zero at one and four,
and negative at the other positive grades. Its lower bound is exactly 1/2.
Integer-valued true counts therefore give c_0≥1, not c_0≥2.

There is no accidental reconstruction hidden in the example. The real
nonnegative histogram

$$
(\tfrac12,6,0,0,\tfrac52)
$$

has the same moments and attains c_0=1/2, proving that the submitted
quadratic is optimal for this real relaxation. The integer histogram

$$
(1,5,0,1,2)
$$

also has those moments, so the rounded conclusion c_0≥1 is sharp even
among integer histograms. Neither counterfeit is asserted to arise from
genuine midpoint prime grades. These receipts make the claimed distinction
between certifying positivity and reconstructing the full interior precise.

## 4. Moment-depth statement

The binomial pair at order r=d+1 has matching moments through d by the
finite-difference identity, including d=0 with the convention j^0=1.
The next moment differs by (−1)^r r!, so it is not a vacuous alias.

For a fixed known support 0,...,L, this also proves the sharp universal
degree threshold for recovering c_0 from polynomial moments: every d<L
has the same pair embedded in that support, while degree L gives the
interpolating zero projector. This is a statement about universal exact
reconstruction over arbitrary nonnegative histograms. It does not forbid
a lower-degree certificate of positivity for particular data, as the
midpoint-ten example demonstrates.

## 5. Independent finite computation

An in-memory audit script built a smallest-prime-factor sieve through 514,
then computed Ω(k)=1+Ω(k/spf(k)). It compared complete grade histograms,
the ceiling, direct unordered prime-pair counts, and the quadratic
inequality with the submitted implementation for all 256 midpoints
2≤n≤257. There were zero discrepancies.

The submitted factorization increments trial divisors and divides them
out; the audit uses an Eratosthenes-style factor table. Direct prime-pair
counting in the audit uses spf(k)=k, rather than either submitted
primality routine or submitted Ω code.

The fixed quadratic's lower bound was positive exactly at

$$
n\in\{2,3,4,5,6,7,8,10,11\}
$$

within the checked range. In particular, it was not positive at any
12≤n≤257. This is a finite negative observation, not a proof of
eventual failure or a counterexample to Goldbach. It argues against
presenting this particular quadratic as an already promising asymptotic
engine.

The probe also directly checked the sharp real, sharp integer, and
support-forged histograms displayed above. No new persistent executable

## 6. Implementation boundaries and minor API note

The verifier rejects an invalid filter sign or normalization and pays
interval error with the correct endpoint for each coefficient sign.
Its attribution string is correctly documented as metadata. Its
proves_positive flag is conditional on the supplied source, support and
response contract, as stated in the module.

At L=0, quadratic_filter returns the one-coefficient trivial filter. A
caller using a degree-two data table must either pad this weight vector
with two zeros or request degree-zero data; otherwise the dimension check
rejects it. The current tested usage handles this correctly. This is an
API usage constraint, not an unsound certificate or a blocking defect.
