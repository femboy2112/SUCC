# Positive causal suspension and negative arithmetic — research index

**Research-only child of SUCC PR #636.** The source origin remains zero; no BBP or completed-Weil source is edited. This package answers whether SUCC's finite positive clock construction can acquire a continuous *causal volume* that connects to negative integer coordinates, and whether Gamma and negative zeta values can be constructed from forward-only processes.

1. [THEOREMS.md](THEOREMS.md): PSV-01..08 — mapping torus, dense forward leaves, Gamma convolution/concentration, negative-depth distributions, Sondow/Euler finite Pascal continuation, zeta zeros, and BBP-to-zeta normalization bridge.
2. `observational_succ/causal_suspension_gamma.py`: exact rational clock and finite-difference computations; Gamma symbols and numeric Fourier checks. The floating complex Fourier values are **not** rigorous enclosures; analytic bounds are in THEOREMS.
3. `tests/test_causal_suspension_gamma.py`: 19 focused unit tests; independent algebraic tests in `independent_oracle.py`; raw receipts under `receipts`.
4. [VALIDATION.md](VALIDATION.md), [NEXT.md](NEXT.md): authority, reproduction and missing source morphism.

**Boundary:** the solenoid suspension is a declared continuous extension, not compelled by compactness; zeta's analytic continuation is a separate classical source theorem, not a property of a generic compact group; `ζ(-2n)=0` is *trivial zero mathematics*, not RH. The BBP Gamma face index contact is a shared scalar normalization, not a BBP→zeta source identification.
