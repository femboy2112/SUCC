# The Source Authentication Forge — Principia Observatoris

Research-only continuation of [PR #628](https://github.com/femboy2112/SUCC/pull/628). The question is whether a recursively modeling observer can authenticate its complete source/likelihood/probe-cost/historical feedback loop and how the author's historical **SimpleField**, **IdealHardField**, **FuckedField** distinctions fit into the result. The answer is a **layered** one, not a physical universal theorem.

**Read [THEOREMS.md](THEOREMS.md)** for mathematical claims and counterexamples, then [VALIDATION.md](VALIDATION.md) for exact execution evidence. [NEXT.md](NEXT.md) names the physical/source boundary.

## What is actually executable

- `observational_succ/source_authentication.py` — exact 2-state P/Q joint source models, retrospective observer, adaptive actions, likelihood-ratio e-process, calibrated source credit charges and an intentionally conservative evidence-based field classifier.
- `source_process.py` — a different Python process with a committed 128-byte OS random tape, hidden initial state and registered read/flip/reset actions. Does not import the observer mathematics. Never discloses hidden state before the end.
- `independent_replay.py` — independent replay from the **revealed** tape, also verifying source code digest, model label binding, observer's policy, posterior, evidence and score.
- `run_live_holdout.py` — actual 24-session (12+12) model P/Q execution; full raw transcript in gzip receipt.
- `independent_oracle.py` — raw-path probability enumeration independent of the recursive filter's transition implementation.
- `tests/test_source_authentication.py` — exact regressions, live subprocess contacts and hostile mutations.

**Important:** the program's cryptographic precommitment and actual execution are finite source-contact witnesses, not proof that an external physical carrier satisfies the same mathematics. CPU wall time is only a measured side channel; credits are a **declared** resource tariff, not calibrated joules. The martingale certificate applies to the modeled readout/action filtration with an ideal uniform-random-tape assumption, not arbitrary stopping based on source digests or timings.

## Field-class outcome

The classes are **source × target × toolkit**, not intrinsic categories of objects:

1. `SimpleField`: a proven finite uniform target query interface in an adequately declared source.
2. `IdealHardField`: global existence proved, computable witness ruled out by theorem.
3. `FuckedField`: one of three *proved* defects—global nonexistence, target nonidentifiability, or phantom lift outside the original source class.
4. `Unresolved`: the current toolkit/source evidence does not decide an obligation.

These must not be collapsed into a scalar. One fully predictive source may still have inaccessible hidden identity; even a successful self-model fixed point can be wrong about source ontology.
