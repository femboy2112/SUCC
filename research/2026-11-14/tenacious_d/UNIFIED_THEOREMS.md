# Unified theorem register

The comparison begins with a proposed quotient \(q\), a selected starting state or source class, a word of lawful operations, and a named target. For a current state \(x\), the question “where can this report eventually go?” joins outcomes over words. The question “what will this action do next?” keeps the word. Distinguishing hidden states need only be possible when an allowed target or intervention needs their distinction. The following are the result contracts for those three choices.

Proof status is attached to the smallest actual result checked. In particular the whole dependency graph has no blanket formal certificate. For a correction against an original statement use the [cross-examination](CROSS_EXAMINATION.md) and [countermodel exchange](COUNTERMODEL_EXCHANGE.md). All external-source applications still require an adequate model of the intended physical carrier. The arithmetic application authenticates a mathematical source by its formula and the given zero initial condition.
