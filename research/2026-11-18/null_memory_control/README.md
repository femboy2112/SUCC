## The three gates

1. **Conserve memory:** a retraction must recover the full prior record: \(\mathrm{retract}(N_0(S))=S\).
2. **Null conditional on the existing record:** \(I(\Theta;Z\mid M)=0\), or the stronger likelihood-family condition \(P_\theta(Z\mid M)=K(Z\mid M)\) for all source hypotheses. Source-independent **marginals alone are insufficient**.
3. **Conserve the next-probe process under sham:** retain action set, policy, source passport, cost/time resources and next-query distribution. A fair source-independent coin can change probe selection even though it cannot update the Bayesian posterior.

A source-independent mask **reused later by a new sensor** is presently posterior-null but has future option value. It is a **deliberate higher-order lift**, not a strongly neutral control. The classic \(A=R,\ B=\Theta R\) construction shows that storing the reference \(R\) changes the conditional information in B from zero to the complete source bit.
