# NEXT — verdict-changing source-first signed π/Collatz experiment

## The exact opening

We now have an **original-source** signed Fourier parity oracle and an **original-source** prime-square *counterfactual* response with uniform imaginary lower bound. The frontier isn't getting more parity bits: it's a genuinely new signed inequality on the *unchanged* zero-seeded π trajectory, not the difference between π and an intentionally altered source.

## Distinguish four observer heads

1. **Literal source head**: `U0=0`, original 4 signed poles, `c_j`, all exact prime-square event times and `4/p²` marks, real cofactor, integer winding and `T_n`; never fit digits post hoc.
2. **2-adic parity head**: source-derived signed Rademacher bits `ε_(4n+j)`; actual shortcut Collatz on the constructed 2-adic shadow, which is not presumed an ordinary positive integer.
3. **3-adic arithmetic head**: returned odd representative modulo3 on *finite integer cylinder lifts* with `(-1)^v`; source ancestor, branch clock and inverse precision retained. No false continuous Z2→Z3 conjugacy.
4. **Root/Haar head**: actual `H` idempotents only on Q2/t-adic higher precision, 2 extra bits paid; original root projector is NOT a parity bit. Calibrate two independently sourced channel references, original orientations and 5/11 auxiliary signature.

## Positive route: source-selected zero-seed antisymmetric quarter response

Define on the actual π orbit, with **no perturbed source**, `q_n=ε_(4n+2) XOR ε_(4n+3)=1_{cos(2π16^n x)<0}`. Prove a new all-sufficiently-late integer-shell lower bound `liminf_B B^-1 Σ_(n=B)^(2B−1) q_n >0`. This implies R0 by the exact comparison in SFC-03 but is not equivalent to R0; zero-and-one-only-digit countermodels kill the reverse. It requires a source-specific arithmetic mechanism controlling the actual phase relative to the quarter thresholds.

Candidates to test, *without assuming the conclusion*: original prime-pole/cofactor **signed** characters, carry-conditioned asymmetric root ports (paying 2-adic precision), and longitudinal source journal correlations with quarter-phase Fourier modes. Predeclare mode, source marks, delayed windows, Gaussian width/reference, and held-out prime clocks. Put original-source phase only in the final measured target, not in the construction of a fictitious source-only witness.

## Negative route: a useful conditional observability price

Use SFC-01 to determine whether a source-faithful, precision-budgeted map exists from the exact H root projectors and original p² residue marks to the **actual** 2-adic parity head. Any candidate must specify an integral basis or pay the two-bit 2-adic precision cost; preserve the source's full cofactor and literal original seed. Need an actual intertwiner of updates, not just matching root locations at 1/4 and3/4. Compare the finite response on an unperturbed prefix, and on a new independent holdout region.

- Original forcing, shifted seed `s=1/16`: late circle aliases, source head rejects.

- Arbitrarily long finite near-zero runs and delayed source mutations: local data cannot certify all late shells, no finite-to-infinite promotion.
- Collatz source sibling CSTC / CYC / PD: no density-average or 2-adic Bernoulli-genericity argument solves positive-integer universal orbit termination.
