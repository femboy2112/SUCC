## CCS-01. A seam is a failure of target-relative reconstruction

For a nonempty source set X, map f:X→Y and target t:X→T, there exists a unique t_bar:f(X)→T with t=t_bar∘f iff t is constant on every fiber of f. Proof: necessity is substitution; sufficiency defines t_bar(f(x))=t(x), well-defined by the condition. Thus noninjectivity collapses source distinctions, but not necessarily target distinctions. Injective nonsurjective f preserves every source distinction and excludes target points outside f(X); replacing the codomain with the actual image removes that set-level exclusion. Surjectivity and injectivity are independent. A bijection has a set inverse but it may not be an admissible, computable, continuous, smooth, stable, or source-authenticated inverse.

For a set of admitted reports E, define x~_E x' iff every report agrees on x,x'. The quotient is the exact object observable by the joint toolkit. Enlarging E refines this partition; reusing the same report does not. For a chain X→Y→Z, the kernel equivalence of the first map is contained in that of the composite. For smooth maps the tangent analogue is ker Df⊆ker D(g∘f) by the chain rule. It holds for the specified downstream maps with no new inputs; independent side channels and higher-order probes may distinguish more.

Crucible: x↦(x,0) into R² is injective but nonsurjective and loses no source value. x↦x² on R loses sign but preserves |x|. A true physical causal boundary requires a lawful source/dynamics contract beyond a generic function.

Verdict: DISCLOSED in declared set/smooth classes. Proposed SUCC nomenclature: state-collapse, reachability, structure, resolution and history seams; keep target dependence explicit.

## CCS-02. Exact correlation-loss ledger, not a value count

Fix a finite source X with strictly positive probability weights p(x), and observation q:X→C. Let H=L²(X,p;R). Let P be the conditional-mean operator given q: on a fiber it replaces a function by its weighted mean. P is the orthogonal projection onto fiber-constant functions: the residual has weighted sum zero within each fiber, hence is perpendicular to every fiber-constant function.

For any finite family of real source observables a_i, put b_i=Pa_i and c_i=(I-P)a_i. Define G_ij=<a_i,a_j>, G_obs,ij=<b_i,b_j>, L_ij=<c_i,c_j>. Then exactly

    G = G_obs + L,  L >= 0 (positive semidefinite).
    rank L = dim span{c_i};  L=0 iff every a_i descends through q.

Proof: mixed terms vanish by orthogonality; for coefficients v, v^T L v=||sum v_i c_i||². The rank statement is Gram rank. Centered covariance satisfies the same formula since P fixes constants. Individual signed off-diagonal entries of L need not be positive. For nested coarsenings q2=g∘q1 the corresponding projections satisfy P2P1=P2=P1P2; the orthogonal residual splits (I-P2)=(I-P1)+(P1-P2). Hence the exact loss matrices add across the chain, not the ranks in general. Duplicate or linearly dependent reports do not create independent rank.

This is a conditional-expectation specialization of Genesis coupling mass: keep full signed pair terms and an explicit residual; it does not assert equality of arbitrary source pair kernels with an L² conditional-mean Gram. No prior-independent numerical loss is implied. For each positive prior the test is exact; only set-level descent is prior-free. Correlations may be computable but unavailable in one destructive single-copy experiment (Genesis causal memory).

Crucible: take a balanced hidden sign a and q constant. Mean of a=0 but variance=1; the missing correlation is real in the source, inaccessible through q. Take a target constant on fibers and L=0 for that target even if q collapses other distinctions. Two observables with residuals a,-a give a negative lost off-diagonal. Replacing L by diagonal norms changes the ledger.

Verdict: DISCLOSED classical theorem; new proposed integration into knowledge volume. Next: test against actual source-conditioned path kernels, not arbitrary numerical Gram matrices.

## CCS-03. A bijective map can fail reversibility at every finite jet resolution

At the pointed real germ (R,0) define A_K=R[t]/(t^{K+1}) and a pointed substitution f*(h)=h(f(t)) mod t^{K+1}. For f(t)=a t^m with a≠0 and odd m≥1, f:R→R is a bijection. Yet

    rank f* = 1+floor(K/m)
    ker f* = span{t^j : floor(K/m)<j≤K}.

Proof: monomial t^j maps to a^j t^{mj} if mj≤K and to 0 otherwise. Surviving monomials are distinct. This is a finite-dimensional exact description of the structure seam, not a statement that the exact inverse of f loses source values. For a general real formal series f=a t^m+O(t^{m+1}), the images have distinct leading orders and the same kernel/rank argument applies. The full formal substitution R[[t]]→R[[t]] is injective for f of finite positive order, but for m>1 not surjective: t is not in the image. Thus an inverse of the point map need not live in the formal power-series category.

If g=b t^n+O(t^{n+1}), b≠0, then g∘f=b a^n t^{mn}+O(t^{mn+1}); orders multiply. The pullback reverses composition as expected. The first nonzero coefficient is a Hasse coefficient; ordinary derivatives multiply by factorial and can hide it modulo p. For smooth f and g with these finite Taylor leading orders the same leading-order computation holds. No scalar order-multiplication assertion for arbitrary multivariate/vector germs without checking the leading homogeneous composition.

Quantitative seam: for real odd m and x,y, |x^m-y^m|≥2^{1-m}|x-y|^m. For same-sign x,y reduce to a≥b≥0 and (b+d)^m-b^m≥d^m; opposite signs use a^m+b^m≥2^{1-m}(a+b)^m by convexity. Hence inverse Hölder exponent 1/m with constant (2^{m-1}/|a|)^{1/m}; exponent cannot improve at zero since |f(t)|=|a||t|^m. Stable recovery has a different scale from exact recovery.

For G_J(s)=s/(s+J), J≠0, the germ at zero has G_J(0)=0, G'_J(0)=1/J, and local inverse s=Jy/(1-y). This rational map is NOT a global R→R bijection (pole, omitted 1). On R\{-J}→R\{1} it is bijective.
